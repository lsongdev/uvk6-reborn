# 频道格式与串口编辑

更新于 2026-11-01。频道记录只有一种规范格式，存储和 PC 链路共用同一段 41 字节，由 [channel-store.c](../src/store/channel-store.c) 的 `CHANNEL_STORE_Encode`／`CHANNEL_STORE_Decode` 编解码。所有多字节整数均为小端。

## 规范记录（41 字节）

| 偏移 | 长度 | 字段 | 取值 |
| --- | --- | --- | --- |
| 0 | 16 | 名称 | ASCII 或 GB2312，最多 16 字节；第一个 `00` 之后全部为 `00` |
| 16 | 4 | RX 频率 | Hz，须落在某个频段内 |
| 20 | 4 | 步进 | Hz，非零 |
| 24 | 2 | 带宽 | Hz；WFM 为 0 |
| 26 | 1 | 模式 | 0 NFM、1 WFM、2 AM、3 LSB、4 USB |
| 27 | 1 | 静噪 | 0–10 |
| 28 | 2 | RX 亚音 | 见下方亚音编码；仅 NFM 可非 0 |
| 30 | 1 | TX 标志 | bit0 允许发射，bit1–2 功率（0 Low、1 Medium、2 High），bit3–4 偏移（0 关、1 +、2 −、3 异频），bit5 尾音；bit6–7 必须为 0 |
| 31 | 4 | 偏移量 | Hz，10 Hz 整数倍，最大 100 MHz；`+`／`−` 使用 |
| 35 | 4 | 异频 TX | Hz，0 表示未设；异频使用 |
| 39 | 2 | TX 亚音 | 见下方亚音编码 |

### 亚音编码

16 位值，高 4 位是类型，低 12 位是数值：

| 类型 | 含义 | 数值 | 例 |
| --- | --- | --- | --- |
| 0 | 关 | 必须为 0 | `0x0000` |
| 1 | CTCSS | 频率，0.1 Hz | 88.5 Hz → `0x1375` |
| 2 | DCS 正码 | 八进制码的值 | D023N → `0x2013` |
| 3 | DCS 反码 | 同上 | D023I → `0x3013` |

只接受固件支持的 50 个 CTCSS 频率和 104 个 DCS 码（[dcs.c](../src/core/dcs.c) 的 `CTCSS_Options`／`DCS_Options`），不在表中的值整条记录拒收。

## 存储

每个频道两份 64 字节副本：标签 `C6`、序号、频道号、`00`，然后是 41 字节规范记录，接着保留字节全为 `00`，最后是字节 0–59 的 CRC32。保存时先写旧的一份并逐字节回读，再写另一份。

早期格式（标签 `C5`，亚音存成内部选项序号）不再读取，视为空频道。从旧固件升级后，原有频道需要重新录入。

## 串口命令

使用现有 PC 链路的帧格式和会话时间戳（`0x0514` 握手，固件版本 `reborn`）。频道号从 1 到 200。

### 读取 `0x0580` → `0x0581`

请求 12 字节：`80 05`、长度、频道号 u16、`00`、`00`、时间戳 u32。

应答：`81 05`、长度、频道号 u16、状态 u8、`00`，状态为 1 时后跟 41 字节记录。

| 状态 | 含义 |
| --- | --- |
| 0 | 空频道 |
| 1 | 后跟记录 |
| 2 | 频道号无效或存储不可用 |

### 写入 `0x0582` → `0x0583`

请求 53 字节：`82 05`、长度、频道号 u16、操作 u8（0 删除、1 保存）、`00`、时间戳 u32、41 字节记录（删除时内容忽略）。

应答：`83 05`、长度、频道号 u16、状态 u8、`00`。

| 状态 | 含义 |
| --- | --- |
| 0 | 完成（删除空频道也算完成） |
| 1 | 记录无效 |
| 2 | 频道号无效或存储不可用 |
| 3 | 写入或回读失败 |
| 4 | 正在发射，未写入 |

写入后，正在使用该频道的 Slot 立即按新内容重新调谐；频道被删除的 Slot 退回 VFO。
