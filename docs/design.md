# 极简单 VFO 与自动接收路径设计

日期：2026-10-10。本文是后续实现的设计规格，依据当前工作区源码整理；不代表以下行为已经全部实现或完成实机验证。当前操作请参见[用户手册](user-manual.md)，设备证据与硬件边界参见[硬件事实](hardware.md)。

当前第一批实现状态与操作见[重构进度](refactor-progress.md)；以下仍作为完整目标规格。

## 1. 目标与已确定的原则

用户围绕三个对象操作：**频段、频率、解调模式**。

- 第一阶段只支持一个活动 VFO；后续扩展多个守听频率。
- 接收芯片由底层根据频率、明确的模式和设备能力选择。用户无需切换 BK4819 / SI4732。
- 不提供 `AUTO` 解调模式。界面始终显示明确的 `NFM`、`WFM`、`AM`、`LSB` 或 `USB`。
- 每个频段可独立编辑模式、步进、带宽、静噪等预设。修改一个频段不影响其他频段。
- 频率输入与上下调谐使用同一个流程，可以跨频段、跨接收芯片连续调谐。
- 频段边界用于匹配预设，不把调频限制在当前频段内。
- 接收方案和发射方案分别计算。能接收、由 BK4819 接收，都不自动意味着可以发射。
- 用户设置与驱动参数分开。共享模型不保存芯片枚举、带宽寄存器值或增益索引。
- 可以直接调整旧 API 并同步更新调用方，不为旧调用形状增加兼容包装。

“自动”仅用于底层选择设备以及应用明确的频段预设；解调模式本身不存在隐藏的自动状态。

## 2. 第一阶段功能范围

保留单 VFO 主界面、频段选择与编辑、数字频率输入、上下调频、模式与步进/带宽调整、信号条、静噪、监听、PTT、必要的全局设置，以及关机前状态恢复。

频道/MR 工作模式、多 VFO 切换、多守听、频谱、扫描、Loot 和寄存器编辑不进入第一阶段主操作流程。实现时通过编译裁剪或移除不再使用的路径释放空间；只隐藏入口不会保证释放 Flash。底层仍可保留被接收和发射流程依赖的公共函数。

物理音量旋钮继续控制听音音量。芯片数字音量作为内部音频配置，避免因为未初始化而静音。显示、背光、键盘锁等作为全局设置，不加入频段预设。

## 3. 用户界面与操作

### 3.1 主界面

主界面显示：

1. 顶部：电池、锁定及必要状态。
2. 频段行：当前频段名称；临时参数覆盖时增加小标记 `*`。
3. 主频率行：实际应用的频率、单位和明确的解调模式；低于 1 MHz 显示 kHz，其余显示 MHz。
4. 底部：左对齐的信号条；发射时显示 TX 状态/功率。

模式必须与当前实际工作的解调模式一致。调谐失败时保留原来实际应用的频率和模式，并提示失败；没有可接收路径时明确显示 `RX --`，不能把旧芯片的声音或测量值当作新频率的结果。

信号条统一外观，测量解释由驱动提供。BK 与 SI 的原始 RSSI 不直接混算，也不把 SI 相对强度标成未经校准的 S 值。

### 3.2 按键设计

| 操作 | 行为 |
| --- | --- |
| 数字键 | 输入 MHz 频率；`*` 输入小数点，MENU 确认 |
| ▲ / ▼ | 按当前步进调频，长按连续调谐 |
| 短按 MENU | 打开当前参数菜单：模式、步进、带宽、静噪、功率、频段 |
| 长按 MENU | 打开全局设置 |
| 侧键 1 | 切换到下一个频段，恢复该频段上次频率并应用其预设 |
| 侧键 2 | 循环切换当前频率可用的明确解调模式 |
| EXIT | 退出菜单/输入，或关闭监听；主界面不再切换 VFO |
| PTT | 仅主界面按住发射，松开恢复接收 |

频段菜单提供“选择频段”“编辑当前频段”“保存当前参数为频段预设”“恢复当前频段默认值”。当前参数菜单增加“监听”开关，用于绕过接收静噪，不改变模式；EXIT 可关闭监听。

侧键操作规则：

- 侧键 1 按内置频段表的固定顺序循环，末尾回到首个频段；此顺序独立于频段匹配优先级。仅匹配用途的宽范围兜底频段不加入快捷循环，但仍可通过频率输入进入。
- 切换频段等同于手动选择频段：恢复上次频率并应用已保存预设，不把离开频段时的临时参数自动保存为预设。目标预设不可用时明确提示，保留此前有效接收状态。
- 侧键 2 按 `NFM → WFM → AM → LSB → USB` 的固定顺序循环，跳过当前频率与设备能力不支持的模式；无 SSB 补丁时不提供 LSB/USB。只有一种可用模式时保持当前模式。
- 模式切换保持频率，重新计算接收路径，并显示实际应用的模式；作为当前 VFO 的临时覆盖，不自动改写频段预设。
- 切换模式时，兼容的带宽和步进直接保留；需要调整时自动使用该模式可用的参数并立即整体应用，无需确认。只有实际调谐频率需要量化改变时，才展示目标频率并确认。
- 主界面短按侧键触发一次切换，长按不重复循环。输入或编辑界面中不触发全局频段/模式切换；发射期间两侧键均不改变调谐状态。

模式调整必须经过能力验证，只显示当前频率可实现的模式。

第一阶段不保留所有历史长按快捷键。实现时核对系统级键盘分发与主界面处理，避免 MENU、数字键和旧应用入口发生冲突。

## 4. 频段与独立预设

### 4.1 频段定义

频段包含稳定 ID、名称、起止频率、匹配优先级、内置预设和用户覆盖。频段不是接收芯片的能力范围，也不是频道记录的另一种解释。

频段预设字段：

| 字段 | 含义 |
| --- | --- |
| `mode` | 明确的 NFM / WFM / AM / LSB / USB；没有 AUTO |
| `step_hz` | 按键调频步进，用实际频率单位保存 |
| `bandwidth_hz` | 接收带宽，用实际 Hz 表示，或明确的固定带宽状态 |
| `squelch` | 静噪关闭或等级；由接收驱动转换成适用策略 |
| `tx_enabled` | 此频段预设是否允许提出发射请求，默认关闭 |
| `tx_power` | 发射功率档；不代表已测量的固定瓦数 |

第一阶段增益采用驱动默认策略，不向普通用户暴露不同芯片的增益索引。发射频率默认等于接收频率，第一阶段不增加偏移、异频、亚音等复杂设置；模型可在后续版本扩展。

频段的 `last_frequency` 单独记录，用于手动选择频段时恢复上次频率。它不是模式/步进/带宽预设的一部分。

### 4.2 内置频段与兜底

预置广播、航空、常用对讲和短波等频段，具体边界和默认参数使用集中定义的表，实施时核对硬件支持和产品目标。频段名称不代表该范围内每个频率都可发射。

内置宽范围兜底配置保证未命中特定频段的有效频率仍有明确名称和参数，例如 HF、VHF、UHF。用户不需要在 EEPROM 中先创建频段才能接收。

匹配规则固定为：

1. 只考虑包含目标频率的频段。
2. 优先级高者优先。
3. 优先级相同时，范围更窄者优先。
4. 范围仍相同时，以稳定 ID 决定，避免结果依赖加载顺序。

范围采用 `[start, end)`，避免相邻频段在同一边界重复命中；全局最高有效频率单独处理。第一阶段允许编辑预设参数，频段范围、名称和优先级采用内置定义；自定义频段创建与范围编辑留到后续。

### 4.3 应用与覆盖规则

- 开机：恢复单 VFO 的最后有效状态，包括明确模式及当前频段内的临时覆盖。
- 手动选择频段：恢复该频段上次频率；没有记录时使用其默认起始频率，并应用该频段预设。
- 在同一频段内调频：保留当前参数，包括临时覆盖。
- 调频跨入另一个频段：应用目标频段完整预设；模式显示随应用结果立即更新。
- 主界面修改模式、步进、带宽或静噪：仅形成当前 VFO 的临时覆盖，频段行显示 `*`。
- “保存为频段预设”：把当前有效参数写入当前频段覆盖，清除 `*`；操作前展示将保存的参数。
- 离开频段：不把临时覆盖自动写入频段预设；再次进入时使用已保存的预设。
- “恢复默认值”：只清除所选频段的用户覆盖，恢复内置预设，不修改其他频段或全局设置。

例如把 70cm 的预设设为 NFM、12.5 kHz 步进、12 kHz 带宽，并把广播段设为 WFM、100 kHz 步进、固定带宽。调到 438.500 MHz 时应用前者，调到 95.900 MHz 时应用后者；屏幕分别显示 NFM 和 WFM。

跨频段应用预设是确定的设置切换。手动指定模式后，在同一频段内不得因为芯片切换而静默替换模式。

### 4.4 编辑与校验

当前入口为 `Settings → Bands`，可编辑全部内置频段的模式、步进、带宽、静噪；`Use current` 复制当前频段的最后有效参数，`Defaults` 恢复草稿默认值，两者均需 `Save` 提交。保存只更新所选频段预设，重新进入频段时应用。频段编辑使用草稿，保存时一次校验全部字段。取消编辑不修改持久化内容。进入模式编辑或改变模式后，带宽菜单随候选能力更新，用户确认最终值后再保存。

- 模式必须有可用驱动能力；SSB 还需要可用补丁。
- 带宽只提供该模式可实现的选项；固定带宽显示 `Fixed` 并禁用编辑。
- 步进必须为正，并可由统一调谐层处理。步进可以大于芯片分辨率，但实际频率必须经过校验。
- 频段预设只能在可支持的目标频率上应用；整个频段不能共用一组参数时，应拆分内置频段。
- 已保存的设置因设备/补丁变化而不可用时，提示具体原因并保留设置；不偷偷改成另一种模式。

## 5. 频率模型与连续调谐

### 5.1 单位与精度

共享模型使用有明确单位的整数 Hz，避免 `uint32_t value` 在不同调用中具有不同单位。新 `UVR2` 持久化使用明确的整数 Hz；仅尚待重写的旧硬件适配层以 10 Hz 为内部单位，不能再将这个单位用于任何新存储记录。

明确区分：

- 请求频率：用户输入或按键计算的目标。
- 可应用频率：按驱动实际分辨率得到的频率。
- 已应用频率：硬件配置成功后提交到 VFO 和主界面的频率。

带宽、步进同样使用明确的频率单位，不保存厂商枚举。以当前代码范围采用 32 位 Hz 足够；乘法、加减和解析过程必须检查溢出，不通过无符号回绕处理负方向调频。

### 5.2 输入与按键

数字输入与上下调频都调用统一的调谐 API。

- 数字输入检查格式、溢出、全局范围和驱动能力。
- 如输入频率需要量化，确认界面展示实际将应用的频率，例如“输入 X，调谐 Y”；用户确认后主界面显示 Y。
- 上下键使用调谐前当前步进计算目标，再根据目标频段的模式和驱动能力确定可应用频率。跨频段后，新步进从下一次按键开始生效。
- 同一频段内步进小于当前模式实际分辨率时禁用该步进选项，避免按键后频率原地不动。
- 量化后的结果必须重新匹配频段并校验方案，避免跨边界后使用错误预设；解析次数有上限，冲突配置返回错误。
- 到全局上下界时停在边界，不在当前芯片范围内回绕。
- 进入不可接收的范围时可以显示目标频率及明确模式和 `RX --`，关闭音频；继续调频可离开该范围。不可接收状态与硬件配置失败分别处理。

主界面正常接收时展示已应用频率；`RX --` 状态下展示无法接收的目标频率并清楚标识状态。不会继续播放旧频率并把它标成新频率。

“连续”指调谐操作不被频段和芯片边界割裂，不承诺任意模式都具有相同频率分辨率，也不承诺切换芯片时完全没有音频间隙。

### 5.3 高频率更新

长按调频时合并尚未应用的目标，优先处理最新目标，不积压大量芯片命令。请求频率更新、硬件应用和 EEPROM 保存分别调度；快速调谐期间不逐步写 EEPROM。

同芯片同模式的小幅调谐走驱动快速路径；切芯片或切模式执行完整配置流程。操作次序由调谐控制器统一管理，避免 UI 直接操作驱动。

## 6. 接收路径与驱动能力

### 6.1 能力定义

每个驱动声明频率范围、明确模式、对应带宽、调谐分辨率、测量字段、准备条件和调谐稳定时间。设备能力还包括芯片是否存在、SSB 补丁是否有效及相关音频路径是否可用。

共享层只读取能力和调用驱动接口。芯片寄存器、SI 模式编号、BK 带宽编号、BFO 换算等保留在对应驱动内。

硬件识别应在启动时完成并缓存，不能在每次调频时反复探测。当前 `BK1080_ReadRegister(1) != 0x1080` 只能作为现有启发式；读失败不能直接证明装有 SI4732。应区分 BK1080、SI4732、未响应和未知状态。

### 6.2 固定选择策略

接收路径由“目标频率 + 用户明确选择的解调模式 + 设备能力”共同确定。芯片频率覆盖重叠不代表解调能力相同，不能只按频率选择芯片。用户界面的 `NFM` 是对讲机使用的窄带 FM，`WFM` 是广播宽带 FM；二者是不同模式。内部旧驱动的 `MOD_FM` 仍是 NFM 的底层表示。

| 模式与场景 | 首选接收路径 | 处理规则 |
| --- | --- | --- |
| 64–108 MHz 广播 WFM | SI4732 | 仅接收；无 SI 且确认有 BK1080 时使用 BK1080，仍须校验其范围 |
| 短波 AM / LSB / USB | SI4732 | SSB 检查补丁；缺失时提示，保持明确模式 |
| NFM 对讲 | BK4819 | 校验该频率的窄带 FM 接收能力；发射资格独立判断 |
| 航空 AM | BK4819 | 按该驱动实际能力校验 |
| 其他组合或重叠范围 | 集中的固定优先级表 | 候选必须匹配频率、模式和带宽 |

例如 100 MHz + NFM 选择 BK4819，100 MHz + WFM 选择 SI4732；20 MHz + NFM 选择 BK4819，20 MHz + AM 选择 SI4732；430 MHz + NFM 选择 BK4819。430 MHz + WFM 没有支持的接收路径，应提示该频率与模式组合不支持，不得静默改成 FM。连续调谐进入不支持组合时按第 5.2 节显示 `RX --`；预设应用失败按第 4 节保留此前有效状态。

BK4819 的窄带 FM 通道不作为广播 WFM 的兜底。即使能调到广播载频并听到部分声音，也不能据此声明支持广播接收；广播信号需要相应的带宽和解调处理，SI4732 还提供立体声及 RDS 能力。SI4732 是接收芯片，选用它的路径不提供发射。

厂家公开资料列出的 BK4819 工作频段是 18–660 MHz、840–1300 MHz；SI4732-A10 列出的广播频段是 LW 153–279 kHz、MW 520–1710 kHz、SW 2.3–26.1 MHz、FM 64–108 MHz。因此按这些标称频段计算，频率交集为 18–26.1 MHz 和 64–108 MHz，交集不表示模式可互换。资料来源：[Beken BK4819 数据手册](https://offer-product.oss-cn-beijing.aliyuncs.com/product/offer/attachment/2216999951400/file/subPdf_729460_326293_20231219-105353923.pdf)、[Skyworks SI4732-A10 数据手册](https://www.skyworksinc.com/-/media/Skyworks/SL/documents/public/data-shorts/Si4732-A10-short.pdf)。这些标称频段与固件扩展调谐范围分开记录，整机能力表还须考虑射频前端和实机验证结果。

相同设备能力、频率和参数产生相同方案，不依赖之前使用哪个芯片。BK4819 的 LSB/USB 路径不能仅因为枚举名称相同，就视为与 SI4732 补丁 SSB 等效；第一阶段不将其作为 SI SSB 的自动兜底。

以上是路由策略，不是实机规格。源码中的 SI AM/SSB 范围和 BK 宽接收范围必须在实机验证后确定最终能力表。

### 6.3 应用流程

```text
目标频率
  → 匹配频段与预设/临时覆盖
  → 校验明确模式、带宽与设备能力
  → 生成接收方案和实际频率
  → 静音并准备目标驱动
  → 应用模式、带宽、增益、频率、音量与静噪
  → 等待稳定，更新测量与音频路由
  → 提交 VFO 状态并刷新显示
```

先生成完整方案，再配置硬件，避免依次设置多个参数时留下半应用状态。无需重配置的快速调谐不执行全套上电流程。

驱动接口返回成功/失败和实际频率；发送命令完成不等于硬件成功，应利用可用应答/状态校验。调用采用有界等待，不因 I²C 无应答阻塞主循环。

硬件失败时尝试恢复此前接收方案，恢复成功才继续显示其为有效接收；恢复失败则关闭音频并显示故障。音频路由更新必须同时考虑芯片、模式及静噪，不能仅依赖静噪布尔值是否变化。

## 7. 发射与接收恢复

未来经整机验证后，第一阶段的发射候选仅为 BK4819 的 NFM 同频发射；当前 RX-only 构建仍禁用全部发射。其他模式或频率组合仅接收，除非后续明确实现并验证对应发射能力。

选择 NFM 并由 BK4819 接收，只说明可以使用其窄带 FM 接收路径，不自动授予发射资格。芯片具备收发能力，也不代表整机的功放、滤波器和天线匹配支持全部芯片工作频段。WFM / SI4732 路径始终仅接收，PTT 不得通过切换到 BK4819 或改变模式来绕过限制。

PTT 按下时独立生成发射方案，并检查：

- 当前接收状态有效，未处于输入、频段编辑或硬件故障状态。
- 当前模式支持已实现的发射流程。
- 当前频段预设允许发射。
- 发射频率落在整机已确认的允许配置范围内。
- 选择的 RX 模式必须明确为 NFM，不能因 PTT 改变模式或从 WFM/SI4732 自动切换到 BK4819。
- 即使 BK4819 可以接收当前频率，若没有经过验证的 TX 白名单，仍然拒绝发射。
- 电池、电压、超时等已有保护条件通过。

`tx_enabled` 不能扩展整机发射能力。接收能力表与发射能力表分开维护；拒绝发射时显示原因。

发射开始前停止接收调谐/后续守听调度，记录完整接收方案。发射期间不接受频率、模式和频段更改，避免 PTT 松开时恢复对象发生变化。松开 PTT 后先关闭发射与功放，再恢复接收配置、测量和音频。未来异频功能也沿用这条流程。

## 8. 数据模型与公共接口

建议把职责拆成以下对象；名称可随实现调整，单位和边界必须保持明确。

| 对象 | 职责 |
| --- | --- |
| `BandDefinition` | 内置 ID、名称、范围、优先级和出厂预设 |
| `BandPreset` | 用户可编辑的明确模式、步进、带宽、静噪和发射配置 |
| `BandState` | 用户预设覆盖及上次频率 |
| `VfoState` | 当前频率、明确参数、当前频段 ID 和临时覆盖标记 |
| `ReceiverCapabilities` | 驱动支持的范围、模式、带宽、分辨率和准备条件 |
| `RxPlan` | 已验证的接收设备与参数、实际频率；运行时生成 |
| `TxPlan` | 独立验证的发射配置；运行时生成 |
| `RadioRuntime` | 已应用方案、收发状态、测量、音频和调谐进度 |

典型 API 职责：

- `radio_tune(context, request)`：输入有明确单位的目标及操作来源，返回结果或排队状态。
- `radio_set_parameters(context, parameters)`：一次校验模式、步进、带宽等，原子提交用户层配置。
- `bands_resolve(frequency_hz)`：只匹配频段，不调谐、不写存储。
- `bands_save_preset(id, preset)`：只验证/保存该频段的预设。
- `receiver_plan(request, capabilities)`：纯方案计算，可做主机回归测试。
- `receiver_apply(plan)`：通过驱动应用方案，并返回实际结果。
- `radio_set_ptt(context, pressed)`：执行独立发射状态转换。

UI 调用面向频率和参数的接口，不再调用 `PARAM_RADIO` 或拼装芯片枚举。测量接口使用传入的上下文/设备，不能读取全局 `vfo` 代替参数；这也为多个守听频率做准备。

单 VFO 实现先持有一个 `VfoState` 和一份 `RadioRuntime`，不需要启动四个 VFO 或维护虚假的活动索引。

## 9. 持久化与启动

当前 `UVR2` 持久化保存全局用户设置、每个频段最后一次成功应用的频率与参数、各频段独立预设，以及单一当前接收配置；内置频段定义只在 Flash。运行时信号强度、芯片探测结果与调谐方案不持久化。

格式为固定字节编码，魔数 `UVR2`，每槽 256 B，共两槽 `0x0000–0x01FF`，包含版本、递增序号、CRC32 及规定单位；不直接写运行时 C 结构或位域。新格式不兼容、不迁移 `UVR1`。

写入要求：

- 一次状态更改先在内存校验，只有成功应用到 RX 硬件的频率和参数才更新持久化候选。
- 调频与设置采用延迟保存，合并连续操作；写入失败时保留待保存状态并重试。
- 通过双槽、递增序号、CRC32、写后回读校验进行提交；写坏其中一槽时仍保留另一份有效记录。
- `0x1E00–0x1FFF` 原厂校准区默认不可写；预留可能存在的 SSB patch 尾区，不混用 LOSEHU 的补丁格式。
- UVR2 格式 2 可读取格式 1 并将原各频段参数继承为独立预设；下一次保存升级格式，配置槽位置不变。不迁移 UVR1 或其他固件格式。未知或损坏的内容进入显式初始化；在用户确认前 EEPROM 写入锁定；初始化不会全片擦除。
- EEPROM 地址 ACK 数量只是启发式，物理容量/页大小需根据实际丝印及地址脚确认。确认前最多 32 B 分块写入，并限制在低 512 B 配置区。

启动先读取配置和探测能力，再恢复单 VFO。无法满足保存模式时显示明确原因，允许用户主动改模式或频率；不将 AM/SSB 静默改为 FM。

## 11. 后续多个守听频率

未来增加多个 `VfoState`，复用相同的频段、参数和方案解析逻辑；频段预设共享，各 VFO 的当前状态独立。

独立的守听调度器负责候选集合、优先级、驻留时间、稳定等待、信号保持和恢复主频率。一次只调度有限数量的候选；空候选立即退出。

多个保存频率不等于全部同时接收。驱动资源分配需要体现每个芯片当前配置，音频选择单独管理；两路硬件能否同时工作和混合/切换音频，须实机验证后决定。

PTT 始终绑定用户指定的主 VFO，不能因守听临时切到某频率就对该频率发射。开始发射时暂停守听，结束后先恢复主接收方案，再恢复调度。

## 12. 实施顺序与验收

### 阶段一：整理单 VFO 基础

裁剪旧应用及多守听入口，建立 Hz 单位模型、明确 FM/WFM 模式、驱动能力和上下文接口。保持已验证的启动与存储保护。

验收：一个 VFO，显示始终有明确模式；侧键 1 按固定顺序切换频段并应用预设，侧键 2 只循环可用模式；主界面退出不切 VFO；只有一个频率时不会进入旧多守听循环；构建留有可持续开发的 Flash 空间。

### 阶段二：统一调谐与音频

实现方案计算、连续调频、实际频率反馈、失败恢复、芯片切换和独立发射判断。

验收：

- `95.92500 → 438.500 → 95.92500` 输入往返，显示与实际应用频率一致。
- 上下键跨广播/对讲及接收芯片边界，不在旧范围内回绕。
- 相同频率/模式从不同起点进入，选择相同芯片。
- 切芯片时静噪始终为开/关的两种情况，音频都正确。
- SI 缺失、SSB 补丁缺失、I²C 超时有明确结果且主循环仍响应。
- 不支持的模式不静默替换；不支持的频率不继续播放旧频率音频。
- 接收范围不能直接成为发射允许范围；PTT 松开可恢复接收。

### 阶段三：独立频段预设与持久化

实现内置频段、独立编辑、临时覆盖、明确保存和有版本的持久化。

验收：

- 修改广播段的模式/步进/带宽，70cm 设置不变化，反之亦然。
- 同频段内调谐保持临时覆盖，跨频段应用新预设。
- 离开再返回频段，使用保存的预设；重启恢复最后 VFO 状态。
- 恢复一个频段默认值不影响其他记录。
- 编辑取消不落盘，快速调频不逐步写 EEPROM，断电不产生半份配置。
- 保存模式、单位及频段 ID 可正确回读，不存芯片私有枚举。

主机测试覆盖匹配优先级、边界、单位/量化、模式/带宽能力、无候选路径、预设覆盖、持久化解析和发射拒绝逻辑。实机测试分别覆盖 BK、SI/BK1080、SSB 补丁、音频、PTT 恢复及断电恢复；构建通过不能替代这些实机验收。
