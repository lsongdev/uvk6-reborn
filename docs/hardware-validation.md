# 实机验收清单（尚未完成）

本文件是测试计划，不代表任何设备已通过。开发设备基线参见 [hardware.md](hardware.md)。

## 刷机前

- [ ] 备份 **整个 512 KiB EEPROM**，并对读回备份进行字节级比对和存档。
- [ ] 核实 EEPROM 物理器件、bank 地址、页边界和写保护接线；ACK 掩码只能提供候选映射，不能替代物理验证。
- [ ] 记录设备 Bootloader、MCU 与射频硬件改装信息；确认镜像编译为 DP32G030 Cortex-M0，raw 文件不大于 60 KiB。
- [ ] 默认构建已开放 TX（`ENABLE_TX=1`）。首次发射前接假负载；不具备条件时用 `make ENABLE_TX=0` 生成仅接收镜像。

## 接收与音频

- [ ] 首次启动在未确认初始化前 **不写** EEPROM。确认以后用读回比对确定仅修改受保护配置区。
- [ ] BK4819 NFM 与航空 AM 分别调谐、静噪、音频开启/关闭，检查 VHF/UHF 滤波器切换。
- [ ] SI4732/BK1080 接收存在时，测试模式切换、音频静音、失败后原接收状态恢复。
- [ ] 反复取消 Seek / FC、切换 VFO / Channel / Watch，检查页面状态与实际 RF 归属是否一致。
- [ ] 验证 SSB Patch 的 EEPROM 位置和全量 CRC；缺失、错误、读失败时 SSB 必须不可用。

## 异常与持久化

- [ ] 在独立测试环境模拟 EEPROM 两个副本的单份损坏、写入中途掉电，以及写入后回读失败。
- [ ] 使用可控 I²C 故障注入分别验证 NACK、SCL 持续低电平、释放后的恢复时间；不能无限阻塞。
- [ ] 长时间键盘、背光、UART、扫描及 Watch 切换，测量实际 RAM 栈峰值并和 16 KiB 限额比较。

## TX（默认构建已开放，逐项实测）

- [ ] 用假负载和仪表独立核验 PA、VHF/UHF 滤波器路径、发射功率、调制度、校准数据含义和合法频段。
- [ ] 测量 PTT 松开、TOT、低电压、应用切换、UART/I²C 故障时的 **最大关断延迟**，并验证硬件故障安全路径。
- [ ] 核对 TX 频率误差（已移除 -1.27 kHz 遗留偏移；未写 REG_3B 晶振校准）、Mic gain 默认 16 的调制度与 Deviation 130 的实际频偏。
- [ ] 主机 Mock 测试不等于真实射频安全测试；以上项目未通过前不在空中长时间发射。
