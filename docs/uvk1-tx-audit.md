# UV-K1 发射链路核对

2026-10-19。实现范围：BK4829 NFM 语音、三档原厂 PA 校准、发射亚音和松键后的接收恢复。主机寄存器模型通过不等于射频输出已实测。

- [ApeX 41cc768d](https://github.com/N7SIX/UV-K1Series_ApeX-Edition_v7.6.0/tree/41cc768d946bff97db691ee372b4dbf9bc46743e/App)：交叉核对同源移植的 TX 电源、静音、PA 寄存器。两者不视为独立硬件测量。
- 实机物理 `0x010000` 校准块重新读取，与原厂备份 512 B 逐字节一致；SHA-256 `da3353f563615f969ce51e255618298738f1425119239bb324f0b5aa1b5f5d06`。

## 核对与实现

| 项目 | 原先差异／缺失 | 当前实现 |
| --- | --- | --- |
| 板级许可 | K1 `override ENABLE_TX := 0`，PTT 无法申请发射 | 移除强制关闭，沿用共享 `ENABLE_TX`；各槽 TX Enable 仍默认 Off |
| 接收释放 | 原 TX 只静音、关 RX_ENABLE，未确认所有芯片释放 RF 路径 | `RX_DEVICE_StopAll()` 关闭扬声器并停止已参与接收的芯片；任意失败均拒绝准备 TX |
| PA 校准 | 共享代码内写死 K6 的锚点 | `BOARD_TxCalibration()` 提供板级记录与锚点；只读本机校准，不写 Flash，不使用 K6 参考 PA 值 |
| 发射静音 | REG50 `BB20 / 3B20` 属于 BK4819 | BK4829 使用 `BB18 / 3B18` |
| TX 电源／DSP | REG37 `1D0F` 属于 BK4819 | BK4829：REG36=0、REG37=`9D1F`、REG52=`028F`、REG30=`0000 → C1FE` |
| 语音带宽 | 9k 索引在 BK4829 分支中无效，不会写寄存器 | BK4829 采用参考窄带预置：REG43=`4048` |
| 调制参数 | BK4819 deviation 控制字不能直接视作 BK4829 的实测频偏 | BK4829 保留参考 REG40=`3516`；现有 deviation 字段仅作用于 BK4819 |
| 麦克风 | 原函数还写入参考 K1 没有设置的 REG74 | BK4829 只按参考设置 REG19=`1041`、REG7D 为 `E940` 与 mic 按位或；Mic gain 继续使用共享 0–31 范围 |
| 旁路恢复 | 整字覆盖 REG7E | BK4829 只更新位 5:3 为 5，保留其他字段；FM 语音滤波 REG2B=0 |
| 亚音 | 已有芯片分支 | 保留 BK4829 CTCSS REG51=`9040`、DCS=`A033`；使用共享码表／Golay 编码 |
| PA 时序 | 已有最后开 PA、最先关 PA | 保留，且 Enable 入口检查失败也执行关闭，清除准备态；延时后复查物理 PTT、电压 |
| 状态灯 | 共享颜色映射复用 K6，K1 实机发射绿灯、接收红灯 | 颜色接线移入板级 HAL：K1 REG33 bit0=红、bit1=绿；K6 原映射保留。共享语义仍为发射红、接收开音频绿 |
| 恢复 RX | 已有状态机和失效缓存 | 松键／TOT／电压异常先关 PA、REG36=0，再关闭 DSP、清亚音、完整恢复 RX |
| 只读诊断 | 缺 TX 调制、静音、亚音增益、Mic 寄存器 | RF 快照补入 REG40／50／52／7D，不增加寄存器写入命令 |

K6 的寄存器行为、原有 PA 插值锚点和两个 TX 范围保持不变；新增板级 HAL 不提供旧 API 包装。

## PA 数据与软件范围

| 范围 | 物理记录 | 插值锚点 MHz | 本机 Low／Medium／High 三锚点 |
| --- | --- | --- | --- |
| 136 ≤ f < 174 MHz | `0x0100F0`，band 2 | 137／155.5／174 | `5F 5F 5F`／`69 69 69`／`91 96 91` |
| 400 ≤ f < 470 MHz | `0x010120`，band 5 | 400／435／470 | `5A 5A 5A`／`64 64 64`／`91 96 91` |

范围沿用项目策略；K1 VHF 锚点来自参考频段表的下界、中点、上界。136–137 MHz 使用 band 2 最低锚点钳位，这是本项目保持 136 MHz 下界的策略，尚未经该边缘频率实测；不使用 108–137 MHz RX band 中的占位 PA 记录。每档任一锚点为 0／FF 或读取失败时，该档不可发射。不复制参考固件中提高 PA 偏置的附加增量。

## 简化流程

`PTT → 对象／模式／频率／校准／电压检查 → 静音并释放接收 → 配置 NFM＋Mic＋亚音 → TX DSP → 等待 10 ms → 原厂 PA 偏置 → 复查 PTT／电压 → PA gate 开`

`松键／TOT／电压异常 → PA gate 关 → PA 偏置清零 → TX DSP 关、清亚音 → 接收完整重配 → 恢复守听`

选中 FM 不会借用其他槽隐式发射；先选择 NFM 槽。事件回话继续使用已有槽归属规则。PTT 等待忙信道检测期间可取消；TOT 默认 120 秒、到期须先松键。
