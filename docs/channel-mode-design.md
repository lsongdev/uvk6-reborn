# VFO 保存频道与频道模式

2026-10-13。本文定义新的用户频道功能。它采用独立频道模型和 EEPROM 区域，不读取、迁移或写入旧版 `CH`／`MR` 频道记录，也不依赖旧频道列表应用。当前设备配置中的 VFO、频段预设和全局选项仍按现行配置格式升级规则保留。

## 模型边界

- VFO 是可连续调谐的工作状态；频道是用户显式保存的频率记忆。两者互不覆盖。
- A/B/C/D 各自选择 VFO 或频道来源，并记住自己的频道编号。`F → 3(VFO/MR)` 只切换当前选中 VFO 的来源；`F → 2(A/B)` 仍切换 VFO。
- 频道保存 RX 频率、模式、步进、带宽、静噪、RX Tone、名称，以及现有 TX Enable／Power／Frequency／Tone 意图。频道数据不授予硬件发射权限，物理 TX 继续由独立硬件安全策略锁定。
- 频道编号稳定且可稀疏使用。空槽可以新建，已占用槽必须确认覆盖；首版不提供频道列表、跳号或删除。
- 当前实现为 128 个稳定编号，每编号两个 48 B 副本，放在 `0xB000–0xDFFF`。该区位于现行 `0x0800–0x0FFF` 配置槽和旧频道读取上限的 1024 条记录保留区之后，并远离 `0x1E00–0x1FFF` 校准区及 EEPROM 尾部 SI4732 补丁。旧频道记录仅作为保留区，不解释其内容。
- 频道记录使用 Hz 和明确枚举，通过独立版本、CRC32 及双副本提交。写入失败不更改运行状态。频道记录与整机 VFO 配置分区，保存单个频道不重写整份配置。写保护只开放配置双槽和专用频道区，其他 EEPROM 地址保持只读。

## 操作

- VFO 菜单的 `Name` 编辑当前 VFO 保存频道时使用的名称草稿；`Save` 打开频道编号选择，VFO 默认选首个空槽，MR 默认选当前频道。空槽直接保存，已占用槽提示覆盖；仅在确认且记录回读校验通过后提交。
- 频道模式上下键选择下一个／上一个有效频道，越过末尾循环；静音、接收与 RDS 归属跟随选中频道。频道模式不以频率步进移动，也不把频道修改悄悄写回。
- `F → 3` 进入频道模式时恢复该 VFO 上次选择的频道；没有可用频道则留在 VFO 并提示。退出回到该 VFO 原有连续频率与参数。
- 数字频率输入仅在 VFO 模式有效；频道模式不把数字误解为频率或频道号。用户先切回 VFO 后可连续调谐。
- 频道模式参数只读；可修改名称草稿并通过 Save 明确覆盖频道。不做频道编辑副本、扫描组、自动写回或频道排序。

## 接收与双守听

频道来源解析为普通 `RxPlan`，复用当前芯片选择、模式能力校验和接收运行时。VFO 当前状态保持独立。PTT／TX 配置取自当前操作 VFO 的有效来源，并继续执行现有 TX capability、频率策略与硬件锁。

双守听候选由各 VFO 的有效来源生成：VFO 来源读取其连续频率状态；频道来源读取所选频道。重复接收方案继续去重，失效频道不触发无界扫描或 EEPROM 写入。接收归属、当前选中 VFO 和频道编号分别显示与保存。

## 持久化与实现顺序

1. 新增独立用户频道模型、固定容量表与双副本记录存储；验证分区边界后才允许写入。
2. 在 VFO 菜单实现名称草稿、频道编号选择、覆盖确认和回读验证。
3. 将每个 VFO 的来源与频道编号纳入当前配置格式；旧格式只迁移 VFO 配置，不迁移旧频道表。
4. 实现 VFO／频道来源切换、频道上下选择、显示和启动恢复。
5. 让双守听从 VFO 或频道来源生成候选，并验证手动调谐、PTT、搜索失败回滚和 RDS 归属。

任何非法或损坏频道都按空槽处理，不能被应用到接收器。配置写入与频道写入各自使用 CRC、回读确认和断电安全提交；不得整片擦除 EEPROM。

## 实现边界

频道管理 UI 独立于 VFO 按键与渲染状态机，只包含名称编辑入口和频道编号保存／覆盖确认。频道列表浏览、数字跳号、复制频道到 VFO 编辑和删除均不实现；MR 用上下键遍历有效频道。频道记录只有有效数据记录，没有删除墓碑格式。
