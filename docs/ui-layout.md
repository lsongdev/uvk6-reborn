# VFO 首屏布局

2026-10-14：128×64 屏幕，顶部公共状态栏占 8 px。每个 Slot 卡片为 128×28，可分别放在 y=8 和 y=36，刚好容纳两张。当前最多启用四项，每页两行，F→2 循环并分页；默认单项接收，可开启独立两项轮询守听。公共状态栏保留标题和状态图标；错误、超时、操作反馈和守听状态统一显示在对应卡片的黑底横条。

卡片**无状态、无动画**：同一份显示数据总是画出同样的像素，不滚动、不按时间轮换，放不下的内容直接裁掉。

## 高度与宽度

| 屏幕区域 | 高度 | 内容 |
| --- | --- | --- |
| 公共状态栏 y=0～7 | 8 px | 左上角 RADIO 标题；电池、锁定、F 前缀等公共状态 |
| 卡片顶部 | 8 px | 黑底横条：选中箭头、A–D、预设修改标记 `*`、频段名（或 RT、临时提示）、右对齐模式 |
| 正文 | 20 px | 左侧活动信息；右侧频率／名称 |

| 正文列 | x | 内容 |
| --- | --- | --- |
| 活动信息 | 0～27 | STEP／RX／TX／SEEK 等，见下表 |
| 主文本 | 30～112 | 频率或名称，右边缘固定在 x=113 |
| 间隔 | 113～114 | 始终留空 |
| 小字栏 | 115～127 | 上半：放不下的尾部（小字）；下半：单位 MHz／kHz |

单位上方的小字栏始终保留。主文本放不下的部分按同一规则挪进这里，再放不下就被屏幕右边缘裁掉，不加省略号。

## 字体

只用两套文本字体：小字 TomThumb（3×5）和中字 MuMatrix（5×7）。正文大字由中字放大两倍绘制，每个点向右多画 1 px 加粗（数字步进 12 px，小数点 4 px）。见 [字库说明](../src/ui/fonts/README.md)。

## 正文

**只有频率**（VFO、没有名称，或正在输入／搜索）：中字 ×2 靠右对齐。按真实字宽能放几个字符就放几个，可用宽度 83 px 恰好容纳 7 个字符（含小数点），例如 `438.506`、`1339.99`、`410.02`。其余位数用小字堆在单位上方，例如 `438.50625` 显示为 `438.506` + `25`，`1339.99998` 显示为 `1339.99` + `998`。不舍入已应用频率。输入草稿超出小字栏时保留末尾（光标）可见。

**名称**（MR 频道名，或广播的 RDS PS）：名称同样用中字 ×2 大字，靠右对齐到 x=113；完整频率改为紧凑格式（如 `438.50625MHz`）放到横条最右侧，模式移到正文右下角原单位的位置。名称放不下时从左边界开始，余下字符用小字接在小字栏上半，再超出就裁掉，例如 `My Chan` + `nnnn`。大字一行约 6–8 个拉丁字符，以后的中文频道名按同一位置和高度绘制。

输入频率和 Seek 期间始终显示大号频率；频率格式统一由 `UI_FormatFrequency` 生成，低于 1 MHz 使用 kHz，省略无意义的末尾零。

## 横条

横条从右往左依次是：模式（有名称时换成紧凑频率）、文本。文本优先级：临时提示 > RDS RadioText > 频段名（MR 为 `CH 012` 等频道标识）；宽度不足时直接裁掉，选中箭头、A–D 和模式始终保留。有名称时临时提示会暂时让出频率的位置，约 2.5 秒后恢复。FC 检测期间，横条显示检测器当前范围（`FC VHF`／`FC UHF`），模式位置显示所选范围（`Auto`／`VHF`／`UHF`），正文实时显示最近一次有效读数，尚无读数时为 `---`。短提示和长提示都显示约 2.5 秒后恢复；FC 检测／试听状态持续显示直至退出。

## 活动信息

| 状态 | 左侧正文 |
| --- | --- |
| 空闲／静噪关闭音频 | `STEP` 与紧凑步进，如 `12.5k` |
| 实际接收、音频打开 | `RX` 与八列阶梯信号图标；测量无效时显示 `--` |
| 发射 | `TX` 与 `LOW / MID / HIGH` 档位 |
| 搜索 | `SEEK` 与箭头 |
| 守听探测 | `DW` 与 `--` |
| 无可用接收路径 | `RX` 与 `--` |
| 硬件失败 | `FAULT` 与 `RX` |

阶梯图标使用已有 0～14 相对信号映射，不把 SI 的相对强度标成未经校准的 S 值。档位不代表实测瓦数。

## 实现与验证

`src/ui/components/radio-card.c` 只有一个入口 `UI_RadioCardRender(y, view)`：接收 `UI_RadioCardView`，不保存任何状态，不访问接收器全局状态。活动状态显式传入，不以 RSSI 有效推断静噪已打开。

`tests/radio-card-regression.c` 验证：×2 加粗宽度、三种频率长度的尾部挪移、输入草稿末尾可见、名称与频率对齐、长名称溢出到小字栏、保留间隔列、Seek 强制显示频率、横条优先级、RT 不影响正文、重复绘制像素一致和越界不绘制。

```sh
python3 tools/ui-preview.py --frames frequency name --output docs/images/vfo-states.png
python3 tools/ui-preview.py --frames max maxtext --output docs/images/vfo-limits.png
```

更多场景见 [开发工具](../tools/README.md#ui-预览)。

只有实际接收且确认信号的项显示有效信号和 RX，探测期间显示 DW。其他项保留自己的频率／文本及步进，不借用活动接收器的 RSSI。RDS 文本缓存按 Slot、频率归属，重新调谐清空当前缓存；活动路径无新数据 15 秒后清空文本。

四项时页面为 A/B、C/D；三项且选中 C 时页面为 B/C。后台接收不改变选中箭头或翻页，公共状态栏 DW 标记报告物理接收归属，包括不在当前页的项。四项分页和双守听的预览见 [多 VFO 与双守听](multi-vfo-design.md)。

顶部状态栏在 VFO、设置及其他页面共用同一布局：电池按全局 Show charge 设置显示图标、百分比或电压，状态图标按电池实际宽度靠右排列，标题在剩余宽度内裁剪；低电量闪烁时仍保留电池占位。F 前缀提示仅在 VFO 等待快捷键时出现。
