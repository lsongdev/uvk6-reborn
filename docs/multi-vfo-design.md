# 多 VFO 与多路守听

2026-10-14。保存四个独立 Slot、启用其中 1–4 项、每页显示两行。启用两项及以上时**守听全部已启用的 Slot**，没有开关；单一扬声器不混播两路。频道来源与频道保存见[VFO 保存频道与频道模式](channel-mode-design.md)。配置格式 8 在格式 7 的 VFO 状态上增加每项的 VFO／频道来源和频道编号。

## 状态和操作

- `RADIO_VFO_CAPACITY` 为保存容量，当前 4；`radio.vfo_count` 为已启用数量，默认 2；`RADIO_VFO_VISIBLE` 为可见行数，固定 2；`RADIO_WATCH_LIMIT` 等于保存容量 4。预算互不替代，不用屏幕行数限制用户状态。
- `Settings → Receive → VFO count` 在 2／3／4 项之间调整。`F → 2` 按已启用数量循环，四项为 A→B→C→D→A。目标方案不可用或调谐失败时保留原选择，不静默修改目标模式。
- 选中 A/B 时显示 A/B，选中 C/D 时显示 C/D；仅启用三项且选中 C 时显示 B/C，保持选中项可见，不绘制第三行。
- A/B/C/D 各自拥有当前 RX/TX 参数、各频段记忆和已确认 RDS 缓存；频段预设共享。新增 C 初始为 2m、D 为 70cm，使用内置初始频率和共享预设。
- 减少启用数量保留隐藏项的频率与参数，隐藏项不参与守听。隐藏了当前选中项时选择回到 A，返回主界面后应用 A。重新增加数量可继续使用原 C/D 参数。
- `Settings → Receive → Slot count` 可设 1–4 个槽，默认 2；单槽时仅显示 A。2026-10-14 起删除 `Dual watch` 总开关和各 VFO 的 `RX Watch`：至少两个槽时守听全部已启用的槽，单槽不守听。EEPROM 中原来的两类字节保留位置，写 0，读取时忽略，格式号不变。
- 保存项／选中项／实际接收归属分别处理。守听可以接收 B 而箭头仍在 A；调频、菜单、搜索和输入始终属于选中项，PTT 见下文的回话规则。选中项不必加入守听组。

## 守听规则

信号源按**行为**分两类，不按芯片分：

| 类型 | 判定 | 例子 |
| --- | --- | --- |
| 常驻源 | 广播芯片（SI4732／BK1080）上的方案，或静噪为 0 的 BK 方案 | 广播、SQ0 的航空频道 |
| 事件源 | 静噪大于 0 的 BK 方案 | 对讲、中继、航空 |

1. **只放一路常驻源**：选中的 Slot 若是常驻源就用它，否则用第一个；其余常驻源不参与守听（一颗 SI 也只能调一个台）。
2. **事件压过常驻**：任何事件源确认有信号，就占用喇叭；广播只是静音，芯片继续接收，RDS 照常更新。
3. **事件之间先到先得**：一路事件正在出声时，其他事件不插入。所有事件都在同一颗 BK4819 上，检查别的频道必须离开当前频道，必然断音，所以这条规则同时也是硬件约束。
4. **讲话不限时，讲完停留 2 秒**：信号消失后在该频道静音停留 2 秒等回复，期间恢复信号就继续播放；2 秒后回到轮询，常驻源重新出声。
5. **选中项没有音频特权**：选中只决定 PTT、菜单和调谐归属；唯一的照顾是开始轮询时先检查它。

只剩一个独立来源（重复的方案、只有一个常驻源而没有事件源等）时不守听，选中项照常接收，横条显示 `DW: one source`，2 秒后再评估。SSB 不参与守听（`DW: SSB off`），方案不可用显示 `DW: unavailable`。

### 调度

- 广播常驻源只在开始时调谐一次（若它已经是当前接收方案则直接沿用），之后一直接收；准备失败 2 秒后重试，事件轮询不受影响。
- 事件源在 BK 上轮流检查：静音调谐（不影响另一颗芯片）→ 等 180 ms → 检查信号 → 80 ms 后再确认 → 占用喇叭，此后每 50 ms 检查一次。
- 常驻源也在 BK 上（SQ0）时：每轮询完一圈事件，回到常驻频道放音 1 秒，再开始下一圈。离开常驻频道前先静音，所以每圈会有一段断音，事件越多断音越长。
- 调谐或读信号失败的事件源冷却 2 秒；全部冷却时整组 2 秒后重试，期间恢复选中项接收。

| 参数 | 当前值 |
| --- | ---: |
| BK 调谐后稳定等待 | 180 ms |
| 信号二次确认 | 80 ms |
| 占用期间检测间隔 | 50 ms |
| 讲完后的停留 | 2 s，静音 |
| BK 常驻源每圈放音 | 1 s |
| 失败冷却／全组重试 | 2 s |
| 手动操作后暂停 | 2 s |

### 性能提示（写入用户手册）

- 每个事件源检查一次约 200 ms（调谐 + 稳定 + 读取）。N 个事件源轮一圈约 N × 200 ms，短于这个时间的呼叫可能漏掉；频道越多，发现越慢。
- 一路事件正在出声时，其他事件源都不检查，这期间的呼叫会漏掉（规则 3）。
- 常驻源在 BK 上时，每圈都有约 N × 200 ms 的断音。
- 广播常驻源在 SI4732 上时，BK 轮询不影响广播，只在有人讲话时被压掉。

## 信号、音频与归属

`RX_DEVICE_WatchSignal` 独立检测信号，不能把 SQ0 或 Monitor 的常开音频当成命中：BK 使用至少 SQL4 对应的 RSSI／Noise／Glitch 门槛，有非零 SQL 时再检查硬件静噪，RX Tone 必须匹配。常驻源不做信号检测。门槛仍需信号源实测。

`WATCH_Owner` 是正在占用喇叭的 Slot，`WATCH_Probe` 是正在检查、尚未出声的事件源。标题 `DW A/B/C/D` 显示占用喇叭的 Slot，全部安静时为 `DW -`；正在检查的那张卡片左侧显示 DW，占用喇叭的卡片显示 RX 和阶梯信号。守听不改变页、选中索引、用户频率、频道来源或 TX 参数，不触发保存。RDS 只跟随 SI WFM 常驻源，即使 BK 事件正占用喇叭也继续更新它自己的 Slot 缓存。

## 抢占、PTT 与持久化边界

**只有改动射频的操作才暂停守听**：调谐（上下键、输入确认、频段／模式／步进等接收参数修改、切换 Slot 或来源、频道切换）、Seek、PTT 和离开主应用。FC 只借用 BK：设备为 BK 的 Slot 暂时移出守听，广播 Slot 继续，FC 结束后立即恢复。翻菜单、输入频率草稿、确认页、频道保存页和 F 前缀都不暂停，守听照常运行、广播照常播放。暂停时先静音并停止所有参与芯片，再完整恢复选中项（回话时恢复回话 Slot），不能遗留后台音频；操作后 2 秒再恢复守听，连续操作会顺延。恢复失败则明确提示和静音。

**PTT 回话（talkback）**：某个事件 Slot 正在出声，或在它讲完后的 2 秒停留内，按 PTT 回复这个 Slot：恢复它的接收方案，用它自己的发射配置（TX Enable、发射频率、亚音、功率；MR 来源用频道里的配置）发射，忙信道禁发也检查它。该 Slot 不能发射时（TX Enable 为 Off、未校准等）拒绝并提示原因，**不**退回到选中项发射。其他时候 PTT 发射到选中项。回话不改变选中箭头，发射中的卡片显示 TX；松开后停留在该 Slot 正常收听，2 秒后恢复守听。键盘锁仍保留 PTT release 优先处理。

守听的临时调谐只改变 RF 运行时，不更新用户频率、各频段记忆、选中索引，不请求 EEPROM 保存，不重置用户的频率／名称显示计时。只有修改 Slot count 才请求配置保存。

## 配置格式 7 与 8

格式 7 保存容量增至四项，每 VFO 磁盘字段为 170 B（此前 169 B 加 Watch 1 B）；头部 16 B、Count／Selected／总开关 3 B、共享预设 90 B、全局设置 21 B。格式 7 固定记录内容共 **810 B**。格式 8 每个 VFO 再加入 1 B 来源和 1 B 频道编号，记录内容共 **818 B**；两者都放入 1024 B 槽，CRC 覆盖整槽。格式 7 只迁移 VFO 与全局设置，新增来源默认为 VFO，不迁移旧频道记录。

| 地址 | 用途 | 普通固件写权限 |
| --- | --- | --- |
| `0x0000–0x03FF` | 格式 4／5／6 的旧双 512 B 槽 | 只读迁移，升级后仍保留 |
| `0x0800–0x0BFF` | 格式 7/8 槽 0 | 配置写入 |
| `0x0C00–0x0FFF` | 格式 7/8 槽 1 | 配置写入 |
| `0xB000–0xDFFF` | 128 个用户频道，每项双 48 B 副本 | 频道专用写入 |
| `0x1E00–0x1FFF` | 原厂校准 | 只读 |
| EEPROM 尾部预留 | SI SSB patch | 只读 |

加载优先选择有效新槽；新槽均无效时读取旧双槽并在内存迁移。格式 4／5 的原状态进入 A，B/C/D 按共享预设初始化；格式 6 完整保留 A/B 和选择，初始化 C/D；格式 7 保留四项 VFO／Watch 状态，新增字段采用 VFO 来源。迁移后默认启用两项、总开关 Off、A/B 参与，避免升级即开始自动调谐。

首次保存写入新槽并在旧序号基础上递增，不覆盖任一旧槽；中断仍可从旧记录恢复。此后新双槽轮换、CRC 与回读校验。用户频道使用独立双副本和 CRC，不与配置槽共写；旧频道区内容不迁移也不解释。只扩展明确写入区域，不擦除整片，不碰校准和补丁。旧固件不会读取新配置，降级可能恢复升级前的旧状态，不承诺同步。

API 显式接收输入记录长度，以 512 B 解码旧格式、1024 B 解码新格式，拒绝长度不符。容量预算基于固定官方绿色 UV-K6、512 KiB EEPROM；并不把 MCU RAM 当作 512 KiB。CONFIG_Load/Save 顺序复用单个候选，避免随着容量增加保留三份完整配置在栈上。
