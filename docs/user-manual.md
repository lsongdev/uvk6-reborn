# UVK6 Reborn 中文用户手册

更新于 2026-10-13，依据 Radio 主应用、RadioSlot 与双守听实现。本文描述当前可达的界面与操作；后续设计见 [design.md](design.md)，实现与验收进度见 [refactor-progress.md](refactor-progress.md)。代码行为与实机接收效果分开判断，硬件依据见 [hardware.md](hardware.md)。

## 当前功能范围

默认启用 A/B 两个 Radio Slot，可在 Settings → Receive → Slot count 启用 2／3／4 项，每页显示两个。主屏幕不区分 VFO 或 MR；`F → 2(A/B)` 在 Slot 间循环选择，`F → 3(VFO/MR)` 切换所选 Slot 的频率来源（直接调频或存储频道）。切到 MR 不覆盖原先的 VFO 频率和频段记忆，切回时恢复；可选双守听按每个 Slot 当前来源轮询。Slot 的 TX 设置和 Watch 资格独立，频段预设共享。首次初始化 A 为 145.500 MHz NFM、B 为 438.500 MHz NFM。固件根据频率、模式及探测到的芯片能力选择接收路径，无需手动选择芯片。模式为 `NFM / WFM / AM / LSB / USB`，没有 `Auto`。

默认的生产编译 **TX 在编译期禁用**：可保存各 VFO 的 TX 意图、Tone、功率和独立频率以及 TOT/Busy Lock 参数，但这些设置不构成实际射频授权，按 PTT 不会开启 PA。实验性 TX 路径仅供具备假负载和仪表的受控硬件验收使用。已支持命名频道和频道模式；`F → 4` 可启动 FC 频率捕获、`F → *` 可启动向前 Seek。旧扫描 / Loot 应用目前没有入口。

## 刷写固件

连接编程线，关闭电源，按住 PTT 开机进入 Bootloader。在仓库根目录运行 `make flash PORT=/dev/cu.usbserial-1420`；Linux 示例串口为 `/dev/ttyUSB0`，替换为实际设备路径。命令会先编译再刷写，全部块确认后重新开机。失败时重新进入 Bootloader 并完整重刷。

刷机不初始化 EEPROM；详细步骤和依赖见 [工具说明](../tools/README.md#刷机)。

## 首次开机与初始化

已有有效 `UVR2` 配置时，开机恢复上次保存的频率和参数。旧 Hawk5、LOSEHU 或未知配置不会自动迁移。

无法读取有效配置时进入初始化界面，EEPROM 写入保持锁定。初始化会覆盖低地址的配置区域，也可能覆盖旧固件在该区域的设置或频道内容；操作前备份 EEPROM 并核对本机存储布局。

1. 显示 `No UVR2 config` 时，按 `0` 进入确认。
2. 显示 `Initialize UVR2?` 时，按 `1` 初始化；按 `EXIT` 取消确认。
3. 写入及回读校验成功后自动重启，默认进入 **2m，145.500 MHz，NFM**。

`EEPROM unknown / Cannot initialize` 表示无法初始化；`Write/verify failed` 表示写入或校验失败。`EXIT` 返回初始提示，不会绕过初始化进入接收界面。开机检测到 `EXIT` 按键也会进入该界面。

初始化只写 `0x0800–0x0FFF` 的两份 1024 B 配置槽，不进行全片擦除。具体保护范围见 [hardware.md](hardware.md#必须保护的存储区域)。

## 快速开始

1. 在主界面输入 `438*500`，按 `MENU`，目标为 **438.500 MHz**。进入 70cm 频段时采用该频段预设；初始参数为 NFM。
2. 短按侧键 1，或短按 `F` 再短按 `1(Band)`，依次切换内置快捷频段。
3. 短按侧键 2，或短按 `F` 再短按 `0(FM)`，循环切换当前频率可用的模式。
4. 按 `▲ / ▼` 按当前步进调频，按住可连续调节。
5. 短按 `MENU` 修改模式、步进、带宽、静噪、RX Tone 或守听资格；按 `EXIT` 返回。

成功调谐后约 1.5 秒安排保存，连续修改会延后保存。关机前留出写入时间；主界面调谐没有保存成功提示；频段编辑器有明确的保存结果。

## 主界面与按键

主界面顶部保留 8 像素公共状态栏，每个 VFO 组件高 28 像素。组件黑底横条显示选中箭头、A–D、预设修改标记、完整频段名称及右对齐模式。正文左侧空闲时显示步进，接收音频打开时显示 RX 和阶梯信号图标；右侧默认显示大字号频率。主频率、名称和 RDS 共用原生 12 px ASCII 粗体，数字与字母使用同一套字形；频率输入也使用此字库。MHz 前三位小数用大字，额外小数缩小并放在 MHz 上方，保持实际频率精度。低于 1 MHz 使用 kHz，省略无意义的末尾零。调谐后频率停留 1 秒，有名称／RDS 时正文切换为名称，完整频率与单位移入黑底横条；再次调谐立即恢复大字号频率。名称和 RDS 共用区域，超长滚动，无文本时始终显示频率。当前已接入 SI4732 WFM 的 PS 和 RadioText，名称编辑与中文字库尚未实现。A 位于 y=8、B 位于 y=36，选中箭头表示调谐和菜单归属，RX／信号仅属于实际接收项，它可能并非选中项；探测时显示 DW，其余行显示步进。两行显示不表示同时接收；Dual Watch 开启时按参与组轮询。C/D 使用同一布局分页，三项时选中 C 显示 B/C。错误、超时、操作反馈和守听提示统一显示在对应 VFO 的黑底状态条，长文案滚动；短提示约 2.5 秒，长提示延长到完整滚动后，结束后恢复频段名称，频率／名称／RDS 正文和另一行保持显示。菜单产生提示时暂时显示 VFO，提示结束恢复菜单。量化确认界面使用相同的完整频率格式。详见 [VFO 首屏布局](ui-layout.md)和 [RDS 接收与解析](rds.md)。

VFO 标识后的 `*` 表示当前模式、步进、带宽或静噪与该频段已保存预设不同，**不表示尚未保存**。接收音频打开时，该 VFO 正文左侧显示 RX 与阶梯信号图标；不同芯片的信号读数用于参考，不是统一校准的测量结果。

| 按键 | 主界面操作 |
| --- | --- |
| `▲ / ▼` | 增加 / 减少一个步进；按住连续调节 |
| 数字 `0`～`9` | 在选中 VFO 行原地输入频率，并输入第一位数字 |
| 短按 `F → 1(Band)` | 切换到下一个快捷频段，与侧键 1 相同 |
| 短按 `F → 2(A/B)` | 切换选中 VFO，并恢复它的完整 RX 参数；失败时恢复原接收和选择 |
| 短按 `F → 6(H/M/L)` | 当前 VFO 发射功率 Low → Medium → High → Low，自动保存并提示；MR 频道只读 |
| 短按 `F → 0(FM)` | 循环切换当前频率可用的解调模式，与侧键 2 相同 |
| 短按 `F` | 等待副标快捷键；顶部状态区右侧、电池左侧显示 `F` |
| 短按侧键 1 | 切换到下一个快捷频段，恢复该频段最后成功应用的频率，并应用已保存预设 |
| 短按侧键 2 | 切换当前频率可用的模式 |
| 短按 `MENU` | 打开选中 VFO 参数菜单，标题为 VFO A／VFO B |
| 长按 `MENU` | 打开全局设置 |
| 短按 `EXIT` | 关闭监听 |
| 长按 `F`（副标 `#`、钥匙图标） | 锁定 / 解锁键盘 |
| `PTT` | 当前 VFO 的 TX Enable 设为 On 后，按住进行 NFM 发射，松开恢复 RX；只开放 136–174／400–470 MHz，要求本机功率校准和有效供电 |

侧键不承担旧手册中的监听、手电筒或 SSB ±50 Hz 微调功能。在参数菜单和频率输入中，侧键不执行全局频段 / 模式切换。

副标快捷键采用顺序操作，无需同时按住。目前实现 `F → 1` 切频段、`F → 0` 切模式、`F → 2` 循环 VFO、`F → 3` 切换 VFO/MR、`F → 6` 切换发射功率、`F → 4` 频率捕获和 `F → *` 搜台；其他目标键显示 `Not supported`，不进入频率输入。执行一次后退出前缀；再次短按 `F` 或短按 `EXIT` 可取消，3 秒未执行也自动取消。PTT、长按 F 锁键、进入设置或其他界面会清除前缀。菜单中 F 保留原有局部操作，数值编辑期间短按 F 不执行操作。侧键功能暂不可配置，后续设计见 [统一绑定规则](design.md#33-f-前缀与副标快捷键统一绑定规则)。

键盘锁定后，两个侧键也被锁定，防止误调谐。默认 PTT 不受键盘锁影响；全局设置 `Lock PTT too` 为 `On` 时，PTT 也被屏蔽。该选项不改变 TX Enable 或板级发射范围。

## 频段与独立参数

侧键 1 的循环顺序为 **LW → MW → SW → FM Radio → Airband → 2m → 70cm → LW**。VHF、UHF 是宽范围兜底配置，不加入侧键循环；可通过频率输入或连续调频进入。

下表是首次初始化的默认值，范围用于固件匹配，不能据此认定整机在全部频率上都有可用接收能力。

| 频段 | 匹配范围 | 初始频率 | 模式 | 步进 | 带宽 | SQ |
| --- | --- | --- | --- | --- | --- | --- |
| LW | 150 ≤ f < 530 kHz | 225 kHz | AM | 1 kHz | 6 kHz | 0 |
| MW | 530 ≤ f < 1800 kHz | 999 kHz | AM | 9 kHz | 6 kHz | 0 |
| SW | 1.8 ≤ f ≤ 30 MHz | 7.1 MHz | AM | 5 kHz | 6 kHz | 0 |
| FM Radio | 64 ≤ f ≤ 108 MHz | 95.9 MHz | WFM | 100 kHz | 固定 | 0 |
| Airband | 118 ≤ f < 137 MHz | 125 MHz | AM | 8.33 kHz | 6 kHz | 0 |
| 2m | 144 ≤ f < 148 MHz | 145.5 MHz | NFM | 12.5 kHz | 12 kHz | 4 |
| 70cm | 430 ≤ f < 440 MHz | 438.5 MHz | NFM | 12.5 kHz | 12 kHz | 4 |
| VHF | 30 ≤ f < 300 MHz 的兜底 | 151 MHz | NFM | 25 kHz | 12 kHz | 4 |
| UHF | 300 ≤ f ≤ 1340 MHz 的兜底 | 445 MHz | NFM | 25 kHz | 12 kHz | 4 |

重叠时优先匹配更窄的频段，例如 95.9 MHz 匹配 FM Radio。当前可输入范围为 150 kHz～1340 MHz，但频率和模式组合仍须有可用接收路径。

各 VFO 独立保存每个频段最后成功应用的频率和参数，共享独立频段预设。调到其他频段时恢复其频率并应用预设；同频段内保留当前 VFO 参数。开机恢复最后选中 VFO 和其状态，包括临时调整，不强制替换成预设。F→2 恢复完整当前参数，不重新套用预设；输入、搜索、确认、菜单及 PTT 生命周期内不能切换。目标模式不可用时不静默改变模式或选择。

### 频段列表编辑器

长按 `MENU` 进入 `Settings`，选择 `Band presets` 按 `MENU`。列表包含全部 9 个内置频段，`▲ / ▼` 选择，`MENU` 编辑，`EXIT` 返回设置。频段名、范围和侧键循环顺序采用内置定义，当前不能新增、删除或改名。

编辑界面显示所选频段名，`▲ / ▼` 选择项目，`* / #` 向后 / 向前调整，`MENU` 也可向后调整。模式、步进、带宽使用与主界面相同的能力筛选；模式改变时必要的步进和带宽自动调整，WFM 带宽为 `Fixed`。

| 项目 | 操作 |
| --- | --- |
| `Mode / Step / BW / SQ / RX Tone` | 编辑所选频段的模式、步进、带宽、静噪、接收亚音草稿 |
| `Use current` | 按 `MENU` 将最后成功接收的当前 VFO 参数复制到草稿；仅可用于当前频段 |
| `Defaults` | 按 `MENU` 将该频段内置默认参数复制到草稿 |
| `Save` | 按 `MENU` 校验并保存所选频段预设，成功返回列表 |

`EXIT` 丢弃全部草稿并返回列表。`Use current` 和 `Defaults` 都需要再执行 `Save` 才会保存。恢复默认值不改变上次频率、其他频段或全局设置。

保存时以所选频段上次成功使用的频率校验模式和参数。缺少接收芯片 / SSB 补丁时显示原因；`Save failed` 表示写入或回读校验失败，原预设保留，草稿仍可重试。成功显示 `Saved: next band entry`，表示预设在下次进入该频段时应用，当前接收保持原配置。即使编辑的是当前频段，同频段继续调频仍保留当前 VFO 参数；先切到其他频段再切回来即可应用。

当前保存为 UVR2 **格式 8**，两份 1024 字节槽位位于 `0x0800–0x0FFF`。格式 7 配置保留四项 VFO 和全局设置，新增的频道来源默认 VFO。用户频道单独保存在 `0xB000–0xDFFF`，旧频道表不迁移。不会主动擦写原机 `0x1E00–0x1FFF` 校准区或 EEPROM 尾部 SI4732 补丁。

## 频率输入

频率直接在选中 VFO 的原频率位置输入，另一行保持显示；输入草稿不会调谐或保存。输入始终以 **MHz** 为单位，即使主界面当前显示 kHz。光标用下划线表示，编辑期间暂停名称／RDS 切换和双守听。

| 操作 | 按键 |
| --- | --- |
| 输入数字 | `0`～`9` |
| 输入小数点 | `*`；先输入整数部分，例如 `0*401` |
| 确认 | `MENU` |
| 删除最后一位 | 短按 `EXIT` |
| 立即取消整个输入 | 长按 `EXIT` |
| 取消输入 | 内容为空时短按 `EXIT`；PTT、短按 F、上下键和侧键在编辑期间不执行操作 |

示例：`0*401` → 401 kHz；`95*925` → 95.925 MHz；`438*500` → 438.500 MHz。建议显式输入 `*`，避免依赖自动补小数点。超出允许范围时不会提交。

硬件无法精确表示目标频率时显示 `Apply ...?` 和实际将调谐的频率；按 `MENU` 应用，按 `EXIT` 取消。只有频率量化改变需要这个确认，切换芯片本身不要求确认。

## 模式与接收芯片

侧键 2 或 `F → 0` 按 **NFM → WFM → AM → LSB → USB** 循环，跳过不支持的模式。仅剩当前模式时显示 `No other mode`。`0(FM)` 在本项目中是解调模式入口；FM 广播通过频段选择或频率输入进入。

| 模式 / 组合 | 当前接收路径 |
| --- | --- |
| NFM | BK4819；固件模型下限为 15.88 MHz |
| WFM，64～108 MHz | 优先 SI4732；缺失时可用探测成功的 BK1080 |
| AM，≤30 MHz 且有 SI4732 | SI4732 |
| AM，其他有 BK 接收路径的频率 | BK4819 的现有 AM 实现 |
| LSB / USB，≤30 MHz | SI4732，只有在提供受信任的全量补丁 CRC32 且实际 EEPROM 校验通过后可用；默认编译禁用 |

NFM 是对讲机窄带 FM，WFM 是广播宽带 FM。95.925 MHz 上从 WFM 切换到 NFM / AM 会自动选择对应接收路径，参数兼容调整立即应用。需要时自动调整带宽或最小步进；频率未改变就不弹确认。界面始终显示实际选择的明确模式。

补丁和固件扩展频段的实机效果须单独验证，参见 [hardware.md](hardware.md)。

## 当前 VFO 参数菜单

短按 `MENU` 打开菜单；`▲ / ▼` 选择项目，`*` 增加 / 向后切换，`#` 减少 / 向前切换，`MENU` 与 `*` 相同。`RX Mode` 项的三个修改键均向后循环。`EXIT` 返回主界面；修改成功后立即生效，返回不会撤销。

菜单不设分组标题，直接使用 RX／TX 项目前缀：RX Mode、RX Step、RX Bandwidth、RX Squelch、RX Tone、TX Enable、TX Power、TX Frequency、TX Tone、RX Watch。项目统一左对齐、数值右对齐，当前选中项整行反白。每屏最多五项，超出后滚动；Monitor 已移除，列表末尾为 `Name` 与 `Save`。Name 编辑最多 10 个字符的频道名称草稿；Save 选择频道编号，空槽直接保存，已有频道需再次按 MENU 确认覆盖。

| 项目 | 含义 |
| --- | --- |
| `RX Mode` | 当前明确解调模式，跳过不可用模式 |
| `RX Step` | 调谐步进，使用可读单位，如 `12.5 kHz`，跳过当前组合不支持的值 |
| `RX Bandwidth` | 接收带宽，使用可读单位，如 `12.5 kHz`，跳过不支持的值；WFM 显示 `Fixed` |
| `RX Squelch` | 静噪等级，0～10 |
| `RX Tone` | Off、50 个 CTCSS 频率、104 个 DCS 正码／反码；仅 NFM 可编辑 |
| `TX Enable` | 选中 VFO 的发射意图，默认 Off；不是硬件许可 |
| `TX Power` | Low / Medium / High，使用对应原厂校准档；缺少校准的档位拒绝发射 |
| `TX Frequency` | Same 跟随当前 RX，或独立 TX 频率；MENU／* 原地编辑，# 恢复 Same |
| `TX Tone` | Off、CTCSS、DCS 正码／反码，独立于 RX Tone 保存 |
| `RX Watch` | 是否加入守听组，最多两项 On；需开启 Receive → Dual watch 才运行 |
| `Name` | 编辑频道名称草稿；需要按 Save 写入频道 |
| `Save` | 选择频道编号；空槽保存，已占用频道需确认覆盖。写入后回读校验 |

## 频道保存与频道模式

在 VFO 菜单选择 `Name` 编辑名称草稿，选择 `Save` 打开频道编号选择。VFO 默认定位到首个空槽；MR 默认定位到当前频道。`▲ / ▼` 选择编号，空槽按 `MENU` 保存；已占用频道需再按一次 `MENU` 确认覆盖，`EXIT` 返回。写入后进行回读校验。当前不提供频道列表、跳号或删除入口。

## VFO 与频道模式

`F → 3(VFO/MR)` 只切换当前选中 VFO。进入频道模式时恢复该 VFO 记住的频道编号；编号失效时尝试第一个已保存频道，没有频道则保持 VFO 模式并提示。频道模式顶部显示 `CH nnn`、频道名称和解调模式；`▲ / ▼` 在已保存频道间循环。频道参数只读，Name 可修改名称草稿，Save 可确认覆盖当前频道。退出频道模式恢复该 VFO 原有频率和参数。数字频率输入、频段快捷键、模式快捷键和 Seek 仅在 VFO 模式使用；先按 `F → 3` 切回 VFO。

频道编号为 1–128，固定编号不因覆盖而移动。当前名称限制为 10 个 ASCII 字符。频道记录保存 RX 频率、模式、步进、带宽、静噪、RX Tone、名称和 TX 用户配置；保存 TX 配置不会解锁真实发射。频道记录使用独立 EEPROM 区与双副本校验；旧频道表不导入。

主界面修改形成当前 VFO 的临时覆盖，并随成功调谐保存以供重启恢复；不会自动改写频段预设。需要保存为预设时，在 `Settings → Band presets` 选择当前频段，使用 `Use current` 后执行 `Save`。RX Tone 随当前 VFO／频段状态保存，也可用 `Use current` 保存到频段预设；切换至非 NFM 模式时清除当前 RX Tone。TX Tone 和 TX Frequency 分别属于各 VFO 的发射设置，切换频段时不自动改写。

RX Tone 的 Off 只使用 Squelch 门限；启用亚音时须同时满足门限和匹配亚音才打开音频（Squelch=0 也不绕过亚音）。CTCSS 显示如 `67.0 Hz`，DCS 显示如 `D023N`／`D023I`。*/# 顺序增减并循环所有选项，MENU 与 * 相同；没有自动亚音扫描。切频、切芯片或重新设置亚音会清除旧匹配状态。

TX Frequency 在菜单当前行原地编辑，进入时显示当前值，首个数字替换整个草稿。* 为小数点，MENU 确认，短按 EXIT 删除、长按 EXIT 取消；输入 0 也恢复 Same。独立频率须为 BK 支持范围内的 10 Hz 整数倍，不接受 660～840 MHz 间的接收空隙。输入不支持的频率时保留旧设置和草稿，并提示 `Invalid value`。保存异频不会重新调谐 RX，也不会自动允许发射；PTT 仍按实际 TX 频率、模式、设备能力及授权检查。TX Tone 已进入发射方案，当前设备不会产生真实射频或发射亚音。

## 全局设置

长按 `MENU` 进入 `Settings`。`▲ / ▼` 选择，`MENU` 进入子菜单，`* / #` 增减值，`EXIT` 返回上层并最终退出。

根菜单依次为 `Display`、`Receive`、`Transmit`、`Lock PTT too`、`Battery`、`Band presets`、`System`、`About`。Display 和 Receive 直接显示参数，不再进入 Backlight、Squelch、Hardware 子菜单；About 固定放在根菜单最后一项。普通设置修改后无需按 MENU 保存，EXIT 返回不会撤销。

[菜单帧缓冲预览](images/settings-menu.png)（上排：根菜单、显示、接收、静噪参数、SI4732 参数；下排：发射、电池、系统、设备信息、恢复确认）。

| 菜单路径 | 含义与操作 |
| --- | --- |
| Display → Contrast | 屏幕对比度，显示 -8～+7，即时生效 |
| Display → Light time | Off／5、10、20、60、120 秒／Always；Off 不触发点亮，Always 保持亮灯 |
| Display → Brightness／Idle light | 点亮／待机亮度，0～15；待机亮度不高于点亮亮度，降低点亮亮度时自动限制待机亮度 |
| Display → Light on RX | Off 不由信号触发；Timed 收到有效信号后按 Light time 熄灯；Receiving 接收音频期间保持亮灯、音频关闭后熄灯。Light time 的 Off／Always 优先 |
| Receive → VFO count／Dual watch | VFO 数量与双守听总开关，具体参与项仍在各 VFO 的 RX Watch 中选择 |
| Receive → SQL open delay／SQL close delay | BK4819 静噪打开／关闭时序档位，分别 Level 0～7／0～3；暂不标注未核实的毫秒数 |
| Receive → SI4732 idle | Mute 静音待机／Power off 断电；下次离开 SI 接收路径生效。无 SI 时显示 No SI，不能编辑 |
| Receive → Filter split | 240／280 MHz，BK 接收滤波切换频率；属于硬件工程设置 |
| Transmit → Time limit | 单次发射时限，30／60／120／180／300／600 秒，默认 120 秒 |
| Transmit → Block if busy | 忙信道发射保护，默认 On |
| Lock PTT too | 锁键时同时锁定 PTT；默认 Off，未锁键时不会禁止 PTT |
| Battery → Show charge | Icon／Percent／Voltage，选择电量显示方式 |
| Battery → Charge curve | 1600／2200／3500 电压百分比估算曲线，不是电池容量检测 |
| Battery → Cal voltage | 按 MENU 在当前行输入实测电压，5.00～8.60 V；首个数字替换草稿，MENU 提交，长按 EXIT 取消。最终校准系数也须合法，保存成功后才采用新值 |
| Band presets | 频段默认接收参数编辑器，保留独立草稿与 Save 操作 |
| About | 固件版本、EEPROM 容量、配置格式、SI4732／BK1080 与 SSB 补丁状态，只读 |
| System → TX status | 当前发射硬件及许可状态，只读；显示所选目标频率的板级支持／校准状态，Ready 不等于已测量 RF 输出 |
| System → Save status | Saved／Pending／Failed／Read only；按 MENU 立即保存或重试，写入失败保留待保存状态 |
| System → Reset prefs | 显示恢复范围；MENU 确认、EXIT 取消。只在写入成功后恢复显示、按键、发射保护和电量显示等偏好 |

退出设置应用时重新应用修改过的静噪时序与滤波边界；失败回退这些工程参数并尝试恢复接收，主界面显示 Tune failed／RX error。减少 VFO 数量时按现有状态约束返回有效项。SI 待机方式在路径切换时使用，发射保护在下次 PTT 使用。

全局偏好统一以 `gDeviceConfig.preferences` 为运行态来源，沿用 UVR2 格式 8 和双槽保存。最后一次实际修改后 1500 ms 合并写入，离开设置时也会尝试提前保存；持续失败按 5 秒间隔重试。Pending 期间突然掉电可能丢失最近修改。电压校准与 Reset prefs 保存失败时原值保留。

Reset prefs 保留电池校准／曲线、接收硬件与静噪工程参数、Mic／Deviation 保存字段，以及全部 VFO／频道／频段预设和守听状态；它不初始化 EEPROM。Beep 暂无可用按键音路径，已从菜单移除；自动锁键尚未开放。真实 PA 输出仍禁用，任何偏好均不能解除硬件限制。

## 提示与排查

| 显示 | 含义与操作 |
| --- | --- |
| `RX --` / `RX unavailable` | 当前频率和模式没有可用接收路径；旧音频停止。换模式或频段再试 |
| `SSB patch missing` | 当前请求缺少有效 SSB 补丁，检查补丁与 EEPROM 布局 |
| `Tune failed` | 新调谐失败，已尝试并成功恢复上一份接收方案 |
| `RX error` | 调谐失败且无法恢复，接收停止 |
| `Invalid params` / `Out of range` | 参数或输入范围不合法 |
| `Band boundary` | 频率量化后落入另一个频段，本次请求未应用 |
| `Fixed bandwidth` | WFM 带宽固定 |
| `TX disabled` | VFO TX Enable 为 Off |
| `TX HW locked` | 当前板级发射实现不可用 |
| `TX calibration missing` | 目标频率／功率档校准缺失或读取失败 |
| `TX out of band` | TX 频率不在 136–174／400–470 MHz |
| `TX battery voltage` | 电池电压未知或超出 6.00–9.00 V，拒绝或中止发射 |
| `TX mode not supported` | 当前模式不是候选 BK4819/NFM |

显示可导航的目标频率不保证接收已成功；确认没有 `RX --`，并检查模式、天线、音量和静噪。FM 广播使用 WFM，UHF 对讲使用 NFM。进入设置后，主界面 `EXIT` 的关闭监听含义不适用于菜单返回键。

不支持的目标不会作为成功接收配置保存。调谐成功也不能单独证明音频链路正常，实机验收进度见 [refactor-progress.md](refactor-progress.md)。

## 多 VFO 配置迁移

当前 UVR2 格式为 8，记录内容 818 B，双 1024 B 配置槽位于 `0x0800–0x0FFF`。配置格式 7 可保留四项 VFO 和全局设置；旧频道记录不迁移。用户频道单独写入双副本区 `0xB000–0xDFFF`。原厂校准与补丁仍只读。旧固件不读取新槽，降级可能恢复升级前状态。

## VFO 数量与双守听

在 `Settings → Receive → VFO count` 设置 2／3／4。F→2 循环，四项为 A→B→C→D→A；页面自动保持选中项可见。减少数量不删除隐藏项频率／参数，但关闭其 Watch；隐藏当前项时回到 A。

`Receive → Dual watch` 默认 Off。每个 VFO 菜单 `RX Watch` 默认 A/B On、C/D Off，最多两项参与；先关闭旧项再打开新项。开启总开关后，固件轮流检查两项，发现信号并再次确认后打开音频。箭头保持操作归属，状态栏 DW A/B/C/D 表示实际接收归属，含当前页之外的项。

调谐、菜单、输入、搜索和 PTT 暂停守听、恢复选中项，手动操作后约 2 秒再继续；守听不会把后台频率保存为选中项或改变 PTT 归属。连续驻留当前最多 3 秒，随后检查另一项，期间可能短暂中断音频；信号消失则静音等待约 600 ms，支持恢复。SQ0 不会把纯噪声视为守听命中。

首批 SSB 不参与轮询，仍可手动接收。有效独立目标不足两个时保持主接收，并显示 DW: select 2／same channel／unavailable／SSB off。稳定等待、亚音判定及跨芯片音频效果仍待设备验证。详见 [多 VFO 与双守听](multi-vfo-design.md)。

顶部状态栏在 VFO、设置及其他页面共用同一布局：电池按全局 Show charge 设置显示图标、百分比或电压，状态图标按电池实际宽度靠右排列，标题在剩余宽度内裁剪；低电量闪烁时仍保留电池占位。F 前缀提示仅在 VFO 等待快捷键时出现。

## FC 频率捕获

连续 VFO 主界面按 `F → 4(FC)` 捕获附近正在发射的强载波。检测文案 `FC detecting` 显示在当前 VFO 黑底状态条，正文保留频率。默认 Auto，每个滤波范围两次尝试后轮换；任一侧键循环 Auto／VHF／UHF。连续两次有效结果相差不超过 3 kHz 才停止检测，进入 `FC Preview` 临时 NFM 试听，显示实际捕获频率。

试听时 MENU 采用到入口选中的 VFO，关闭其 TX Enabled 和 RX Tone，清原频道编号／名称草稿；之后可用 Name／Save 保存。EXIT 恢复原接收状态，检测中 MENU 也取消；15 秒未找到稳定结果自动超时恢复。侧键可从试听重新开始捕获。捕获和试听期间 PTT 不发射，双守听和 RDS 暂停，其他 VFO 不变。试听、取消和超时不保存配置或频道。MR 模式须先 F→3 切回 VFO。

FC 不识别解调模式或亚音，也可能捕获谐波／强信号误报；NFM 试听与频率准确度仍需实机验证。详见 [FC 实现与验收](fc-design.md)。

发射被拒绝时（例如 TX disabled、TX mode not supported、TX HW locked），提示临时显示在选中 VFO 的黑底横条中，替换频段文案，保留 A–D 标识和模式；长文案滚动，提示结束恢复原横条。频率／名称正文保持显示，FC timeout、调谐错误、Seek 状态、频道保存反馈和守听提示也使用同一状态条。

PTT 发射已接入 BK4819 NFM 实际 HAL；初始化默认 TX Enable 仍为 Off，需在当前 VFO 菜单启用。Same／独立 TX 频率及 TX Tone 均进入发射方案，F→6 选择功率档。松开 PTT、超时或供电异常先关闭功放，再恢复原 RX；本轮尚未刷机测量射频输出。实现与校准布局见[PTT 发射链路](tx-design.md)。
