## 快速开始

1. 开机，默认进入 `1 VFO` 主界面；如果修改过 `Main app`，会进入所选应用。
2. 若键盘被锁定，长按 `#` 解锁。
3. 在频率模式按 `1`～`9` 中任意数字键进入频率输入。输入 `145*500`，按 `MENU`，即调谐到 **145.500 MHz**。`*` 表示小数点。
4. 用 `▲` / `▼` 按当前步进调谐。短按 `0` 打开快捷参数菜单，选择 `SQ`，用 `*` / `#` 调整静噪。
5. 按侧键 1 可切换监听模式；再次按侧键 1，或在监听状态按 `EXIT`，关闭监听。
6. 短按 `MENU` 打开应用列表，选择应用后按 `MENU` 进入；长按 `MENU` 打开全局设置。

发射时，在 `1 VFO` 主界面按住 `PTT`，松开发射键结束发射。其他界面中的 `PTT` 可能用于选择频道或返回主界面，请先确认当前界面。

## 按键与通用操作

本文中的短按指按下后松开，长按指按住直到触发长按动作。

| 按键 | 名称 / 用途 |
| --- | --- |
| `MENU` | 菜单键；通常用于进入、选择或确认 |
| `EXIT` | 返回键；输入界面中通常先删除内容 |
| `▲` / `▼` | 上下选择，或调整频率 / 频道 |
| `*` | 星号键；菜单中增加参数值 |
| `#` | 井号键，源码中称为 `F`；菜单中减少参数值 |
| `PTT` | 发射键；列表和扫描界面中也用于选择 |
| 侧键 1 / 侧键 2 | 源码中的 `SIDE1` / `SIDE2`；用途随界面变化 |

### 菜单操作

- `▲` / `▼`：移动选择项。
- `MENU`：进入带 `>` 的子菜单，或执行所选操作。
- `*`：增加 / 切换到下一个值。
- `#`：减少 / 切换到上一个值。
- `EXIT`：返回上一层；顶层菜单返回原界面。

参数通常直接用 `*` / `#` 修改，不必先按 `MENU`。全局设置在修改后约一秒写入存储，修改后稍等再关机。

### 键盘锁

长按 `#` 切换锁定状态，锁定状态会保存。

默认锁定后，`PTT` 和两个侧键仍可使用。如果全局设置 `Lock PTT` 为 `Yes`，锁定时这三个按键也会被屏蔽。`Lock PTT` 只影响键盘已锁定的情况。

## 主界面与 VFO

VFO 是可独立保存频率与接收参数的调谐配置。主界面显示当前 VFO 编号、频率、调制方式、步进及接收 / 发射状态；频道模式显示 `MR` 和频道编号。接收亚音显示为 `R…`，发射亚音显示为 `T…`。收发频率不同时，界面可显示额外的 `TX:` 频率。

### 短按操作

| 按键 | 操作 |
| --- | --- |
| `▲` / `▼` | 频率模式按步进调谐；频道模式切换频道 |
| `1`～`9` | 频率模式进入频率输入；频道模式进入频道编号导航 |
| `0` | 打开 / 关闭快捷参数菜单 |
| `#` | 编辑当前 VFO 的频道参数，并可存为频道 |
| `*` | 打开 `Loot` 信号记录列表 |
| 侧键 1 | 切换监听模式 |
| 侧键 2 | 切换手电筒 |
| `EXIT` | 优先关闭监听 / 快捷菜单或返回；在最底层主界面切换 VFO |
| `PTT` | 按住发射，松开停止 |

SI4732 的 SSB 接收状态下，侧键 1 / 2 优先用于频率微调，每次分别增加 / 减少 50 Hz。

### 长按操作

| 按键 | 操作 |
| --- | --- |
| `1` | 打开频段列表 |
| `2` | 切换内部 `iAmPro` 标志；当前不作为常规操作入口 |
| `3` | 切换频率 / 频道模式 |
| `4` | 切换内部 RSSI 显示标志；实际呈现依界面实现 |
| `5` | 切换当前无线电状态的多 VFO 监听开关 |
| `6` | 切换发射功率档位 |
| `7` | 切换步进 |
| `8` | 调整 `TX offset` 参数；方向另在频道配置中设置 |
| `0` | 切换调制方式 |
| 侧键 1 / 2 | 切换图表测量量；当前主界面图表实现有限 |
| `#` | 锁定 / 解锁键盘 |

### 快捷参数菜单

短按 `0` 打开。用 `▲` / `▼` 选择，`*` / `#` 修改，`0` 或 `EXIT` 关闭。可用项目取决于接收芯片。

| 芯片 | 菜单项目 |
| --- | --- |
| `BK4819` | `Radio`、`ATT`、`BW`、`SQ`、`Mod`、`Step`、`AFC`、`DEV`、`XTAL`、`Filter`、`Power` |
| `SI4732` | `Radio`、`ATT`、`BW`、`SQ`、`Mod`、`Step`、`Volume` |
| `BK1080` | `Radio`、`Step` |

`ATT` 是增益 / 衰减相关参数，`BW` 是接收带宽，`SQ` 是静噪等级，`Step` 是频率步进，`Mod` 是调制方式，`Power` 是发射功率档位。`AFC`、`DEV`、`XTAL`、`Filter` 属于进阶射频参数。

`SI4732` 功能需要设备安装对应硬件；SSB 还依赖相应补丁。选择芯片名称不会为原装设备增加接收硬件。

## 输入频率和名称

### 频率 / 数值输入

| 按键 | 操作 |
| --- | --- |
| `0`～`9` | 输入数字 |
| `*` | 在支持小数的输入中插入小数点 |
| `EXIT` | 删除最后一位；内容为空时退出 |
| 长按 `EXIT` | 清空输入并回到第一项 |
| `MENU` / `#` / `PTT` | 确认；范围输入先确认起点，再确认终点 |

频率输入以屏幕显示的 `MHz` 为单位。例如 `433*125` 表示 433.125 MHz。输入已有内容时，可长按 `EXIT` 清空再输入。

设置扫描范围时，输入起点并按 `MENU`，再输入终点并按 `MENU`。起点高于终点时会自动交换顺序。输入框允许的数值范围不代表硬件在整个范围内都有可用的接收性能。

### 名称输入

频道名称编辑最多允许 9 个字符，以屏幕计数为准。

字母输入采用两步选择：先按字母组的数字键，再按屏幕显示的数字选字符。例如大写模式下，按 `2` 再按 `1` 输入 `A`。

| 按键 | 操作 |
| --- | --- |
| `1` | 字母模式中输入空格 |
| `2`～`9` | 选择字母组，再按对应数字选字符 |
| `#` | 切换大写 / 小写字母 |
| `0` | 切换数字 / 符号模式；数字模式可直接输入数字 |
| `*` | 切换符号模式 |
| `▲` / `▼` | 向右 / 向左移动光标 |
| `EXIT` | 取消字符组选取或退格；光标在开头时退出 |
| 长按 `EXIT` | 清空名称 |
| `MENU` | 确认名称 |

## 频道和频段管理

### 打开和使用列表

短按 `MENU`，选择 `Channels`，按 `MENU` 进入。主界面长按 `1` 可直接打开频段列表。

| 按键 | 操作 |
| --- | --- |
| `▲` / `▼` | 选择记录 |
| `0` | 切换 `CH` 频道、`BAND` 频段、`VFO` 类型筛选 |
| `*` | 循环切换 `INFO`、`TX`、`SL`、`SL SEL`、`DEL` 视图 |
| `#` | 编辑所选记录 |
| `PTT` | 频道列表中调入当前 VFO 并进入主界面；频段列表中选择频段并返回 |
| `MENU` | 普通列表走频段选择流程；存储模式下确认目标槽位 |
| 长按 `0` | 清除当前扫描列表筛选 |

日常调入频道请使用 `PTT`。

### 保存当前频率为频道

1. 在 `1 VFO` 调到目标频率，短按 `#` 进入 `CH ed`。
2. 设置 `Name`、`RX f`、`TX f / offset` 和 `Radio` 子菜单参数。
3. 选择 `Save CH`，按 `MENU`。
4. 用 `▲` / `▼` 选择目标槽位，按 `MENU`。选择已有记录会覆盖该记录。
5. 如果名称为空，会进入名称输入，填写后按 `MENU` 完成保存。

新保存频道的扫描列表成员会被清空，需要在列表的 `SL` 视图中另行分配。

编辑已有频道：在列表选择记录，按 `#`，修改后执行 `Save CH`。编辑当前 VFO 时，参数会同步到当前 VFO；退出编辑不能视作撤销全部修改。

### 频道配置项目

| 项目 | 含义 |
| --- | --- |
| `Type` | 记录类型；切换为频段后使用频段编辑菜单 |
| `Name` | 名称 |
| `RX f` | 接收频率 |
| `TX f / offset` | 发射频率或偏移量，由 `TX offset dir` 决定 |
| `TX offset dir` | `None` 同频、`+` 正偏移、`-` 负偏移、`Freq` 独立发射频率 |
| `Readonly` | 只读标志；当前不应将它当作可靠的防覆盖保护 |
| `Save CH` | 保存到频道槽位 |

`Radio` 子菜单包括步进 `Step`、调制 `Mod`、带宽 `BW`、增益 `Gain`、芯片 `Radio`、静噪类型 / 等级、收发亚音、功率、扰频 `Scrambler` 和 `Enable TX`。

设置亚音时，先选 `RX code type` / `TX code type`，再选对应的 `RX code` / `TX code`。可选择无亚音、CTCSS、DCS 和反向 DCS。改类型后重新核对收发两侧的亚音值。

功率档位为 `ULow`、`Low`、`Mid`、`High`，不代表所有频率上的固定瓦数。当前代码的发射许可检查未使用 `Enable TX` 标志，不能用该项保证禁发。

### 频段记录

频段用 `Bounds` 保存起止频率，用于频段选择和扫描。其他项目包括 `Radio`、功率校准 `P cal`、`Last f`、`PPM`、`Bank`、`Readonly` 和 `Save BAND`。当前 `Last f` 菜单没有完整编辑动作。

### 扫描列表与删除

在 `SL` 视图，短按 `1`～`8` 切换所选记录在第 1～8 个扫描列表中的成员资格；长按 `1`～`8` 对应第 9～16 个列表。可以同时加入多个列表。

在 `SL SEL` 视图，同样的按键修改当前要扫描 / 筛选的列表组合。列表选择是切换相应位，可以组合多个列表；全部取消时表示不按扫描列表筛选。

在 `TX` 视图，按 `1` 切换所选记录的发射许可标志，但当前禁发检查存在上述限制。

在 `DEL` 视图，按 `1` **直接删除所选记录，没有二次确认**。

## 扫描与频谱

从应用列表进入 `Spectrum`、`CH Scan`、`Band Scan` 或 `FC`。扫描发现的信号可记录到 `Loot`。侧键标记的黑 / 白名单属于信号记录，持久保存需在 `Loot` 中执行相应存储操作。

### Spectrum：频谱扫描

屏幕显示扫描范围、信号谱线、步进和扫描速度 `CPS`。底部显示左侧、中心和右侧频率。

| 按键 | 操作 |
| --- | --- |
| `0` | 打开 / 关闭快捷参数菜单 |
| 长按 `0` | 打开频段列表 |
| `1` / `7` | 增加 / 减少扫描延时，每次 100 μs |
| `3` / `9` | 增加 / 减少步进档位 |
| `▲` / `▼` | 移动范围光标 |
| 持续长按 `2` / `8` | 调整光标范围宽度 |
| 短按 `2` | 放大扫描到光标选定范围 |
| 短按 `8` | 返回上一层扫描范围 |
| `4` | 切换分析仪模式与普通频率扫描模式 |
| `5` | 手动输入起止频率 |
| 长按 `6` | 以最近活动信号为中心缩放，范围约为 128 个步进 |
| 侧键 1 | 将最近活动信号加入黑名单并继续扫描 |
| 侧键 2 | 将最近活动信号加入白名单并继续扫描 |
| `*` | 打开 `Loot` |
| `PTT` | 未锁定且存在活动信号时，调到该信号并进入主界面 |

键盘锁定且 `Lock PTT=No` 时，本界面短按 `PTT` 可将最近信号列入黑名单并继续扫描，长按可列入白名单。

### CH Scan：频道扫描

扫描当前列表中的频道，接收时显示频道名称。短按 / 长按 `1`～`8` 切换扫描列表组合，分别对应第 1～8 / 9～16 个列表。

侧键 1 / 2 分别标记最近活动信号为黑 / 白名单；`*` 打开 `Loot`。`▲` / `▼` 调用扫描等待处理，是否立即切换取决于接收状态和超时设置。

### Band Scan：频段扫描

扫描当前列表中的频段及其频率范围。短按 / 长按 `1`～`8` 选择扫描列表组合。`▲` / `▼` 继续扫描；侧键 1 / 2 标记黑 / 白名单后继续；`*` 打开 `Loot`；短按 `0` 打开快捷参数菜单。

当前该界面的 `PTT` 调谐调用存在参数顺序问题，选择已发现信号请通过 `Loot` 进入主界面。

### FC：频率捕获

用于捕获可检测到的信号频率，屏幕显示滤波段、捕获周期、`SQ` 和自动切换标志 `[A]`。当前算法排除 88～108 MHz 的捕获结果。

| 按键 | 操作 |
| --- | --- |
| `1` / `7` | 增加 / 减少捕获周期档位：0.2、0.4、0.8、1.6 秒 |
| `3` / `9` | 增加 / 减少静噪等级 |
| `#` | 切换 VHF / UHF 滤波段 |
| `0` | 切换自动滤波段切换，开启时显示 `[A]` |
| `5` | 切换内部捕获参数，屏幕 `HZ` 数字会变化 |
| 侧键 1 / 2 | 标记最近活动信号为黑 / 白名单 |
| `PTT` | 有最近活动信号时调入该频率并进入主界面 |

当前 FC 中 `*` 没有打开信号列表的动作。捕获效果取决于信号强度、天线和环境。

## 信号记录 Loot

主界面或支持的扫描界面短按 `*` 进入。记录可显示频率、累计接收时间、最近活动时间，以及已识别的 CTCSS / DCS。

| 按键 | 操作 |
| --- | --- |
| `▲` / `▼` | 选择记录 |
| `1` | 按最近活动时间排序 |
| `2` | 按累计接收时间排序 |
| `3` | 按黑名单状态排序 |
| `4` | 按频率排序 |
| 再按当前排序键 | 反转排序方向 |
| `7` | 切换简略 / 详细显示 |
| 侧键 1 | 切换所选信号的黑名单标记，同时取消白名单 |
| 侧键 2 | 切换白名单标记，同时取消黑名单 |
| 长按侧键 1 | 切换监听模式 |
| `MENU` | 调到所选频率并返回原界面 |
| `PTT` | 调到所选频率并进入 `1 VFO` |
| `0` | 删除当前记录 |
| 长按 `0` | 清空全部信号记录 |
| 长按 `5` | 将白名单信号批量保存到空频道，并使用当前扫描列表组合 |
| 长按 `8` | 将黑名单信号批量保存到空频道，并加入第 16 个扫描列表 |
| 长按 `*` | 从存储频道加载黑名单记录 |
| `EXIT` | 返回 |

批量保存完成后显示 `Saved: …`。信号记录主要保存在运行内存中；需要保留的信号应存为频道。单条保存建议用 `PTT` 进入主界面，再按 `#` → `Save CH`；当前 Loot 短按 `5` 的保存流程尚不完整。

## 全局设置

在未被当前菜单占用的界面长按 `MENU` 进入 `Settings`。用 `▲` / `▼` 选项，`MENU` 进入子菜单，`*` / `#` 改值，`EXIT` 返回。

### Scan：扫描

| 项目 | 含义 |
| --- | --- |
| `SQL` → `Open t` | 静噪打开确认时间，以 5 ms 为单位显示 |
| `SQL` → `Close t` | 静噪关闭确认时间，以 5 ms 为单位显示 |
| `FC t` | 频率捕获周期 |
| `Listen t/o` | 有信号时的扫描监听超时 |
| `Stay t` | 信号关闭后的停留时间 |
| `Skip X_X` | 跳过固件判为垃圾的频率 |

超时选项包括毫秒、秒、分钟和 `None`。`None` 表示不设置有限超时；要让扫描在持续有信号时也继续，选择有限的 `Listen t/o`。

### Radio：无线电

| 项目 | 含义 |
| --- | --- |
| `DTMF decode` | DTMF 解码开关 |
| `Filter bound` | VHF / UHF 滤波切换边界 |
| `SI power off` | SI4732 电源管理选项，适用于安装该硬件的设备 |
| `STE` | 发射尾音消除 |
| `Tone local` | 本地提示音相关选项 |
| `Roger` | 发射结束提示音，`None` / `Tiny` |
| `Multiwatch` | 多 VFO 监听选项：`Off` / `On` / `Switch` / `Extra` |
| `Mic` | 麦克风参数，0～15 |
| `Freq corr` | 全局频率校正，屏幕以 Hz 显示 |

多 VFO 监听还受当前应用和监听状态影响。主界面长按 `5` 只切换当前状态，要持久选择监听选项请使用 `Multiwatch`。

### Display：显示

| 项目 | 含义 |
| --- | --- |
| `Contrast` | LCD 对比度 |
| `BL max` / `BL min` | 背光高 / 低亮度 |
| `BL time` | 背光时间：`Off`、5 / 10 / 20 / 60 / 120 秒、`On` |
| `BL SQL mode` | 静噪相关背光模式：`Off` / `On` / `Open` |
| `CH display` | 频道显示偏好：`Name+F` / `F` / `Name`，效果取决于界面 |
| `Level in VFO` | 主界面信号图表选项；当前图表分支未启用 |

### Battery：电池

`Bat type` 选择电池类型，`Bat style` 选择电池显示样式。

`BAT cal` 用于电压校准：先测量实际电池电压，选择该项按 `MENU`，输入实测电压并确认。输入范围为 5.00～8.60 V。仅凭屏幕电量百分比不能判断校准电压。

### 其他顶层选项

- `Beep`：按键提示音。
- `Main app`：开机默认应用，可选择 `1 VFO`、`Channels`、`FC`、`Spectrum`、`CH Scan`、`Band Scan`、`ABOUT`。
- `Lock PTT`：键盘锁定时是否同时屏蔽 PTT 和两个侧键。

`ABOUT` 页面显示固件名称、作者和编译时间。

## 初始化和恢复

启动时检测到需要初始化的存储，或启动读取到 `EXIT` 键时，会进入 `Reset`。需要手动进入时，可尝试按住 `EXIT` 开机。

**这个界面操作会破坏存储数据，没有二次确认。进入后先看清选项再按数字键。**

| 按键 / 选项 | 动作 |
| --- | --- |
| `0: 0xFF` | 清空检测到的整个 EEPROM，会删除设置、频道以及该存储中的补丁等数据 |
| `1: FULL` | 保存当前设置、删除频道记录并建立四个默认 VFO；不是逐字节清空整个 EEPROM |

操作完成后自动重启。默认 VFO 频率为 145.500、433.125、253.550、400.650 MHz，步进 25 kHz，FM，静噪等级 4。默认记录中的 `allowTx` 为关闭，但当前发射检查没有使用该标志。

## 常见问题与当前限制

### 按键无反应

先长按 `#` 解锁。快捷参数菜单打开时，数字键等输入可能由菜单处理；按 `0` 或 `EXIT` 关闭。固件与电脑进行串口交互时，也可能暂时不处理键盘。

### 为什么短按 0 不能输入频率？

主界面先由快捷参数菜单处理 `0`。用 `1`～`9` 进入频率输入后，即可输入 `0`；也可通过频道配置中的 `RX f` 输入。

### 频道或频段不见了

检查列表顶部的类型筛选，按 `0` 切换。检查 `SL SEL` 中的扫描列表组合，或长按 `0` 取消筛选。可用槽位数量随 EEPROM 容量及保留区域变化。

### 扫描一直停在一个信号上

检查 `Scan` → `Listen t/o` 是否为 `None`、静噪是否过低，以及监听模式是否开启。可设置有限超时，或在支持的扫描界面将干扰信号加入黑名单。

### PTT 后显示错误文字

`BAT LOW` 表示电量过低，`CHARGING` 表示检测到充电 / 电压过高，`DISABLED` 表示当前接收芯片不能发射，`UPCONV` 表示上变频配置导致禁发。只有 BK4819 路径支持此固件的发射流程。

### 改装接收功能和未完成项目

SI4732 及其 SSB 功能依赖设备硬件和补丁。BK4819 菜单中的 LSB / USB 名称不等同于安装 SI4732 后的 SSB 接收能力。

当前已知的操作限制包括：`Enable TX` 不参与发射许可检查；Band Scan 的 PTT 调谐调用参数顺序异常；Loot 的单条保存入口不完整；`Level in VFO` 图表分支未启用；部分只读、显示及进阶项目的界面或行为尚未完善。本手册给出了相应可用操作路径，后续固件修复后需同步更新。
