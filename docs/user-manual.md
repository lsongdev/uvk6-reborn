# UVK6 Reborn 用户手册

更新于 2026-10-13，依据 Radio 主应用、RadioSlot 与多路守听实现。本文描述当前可达的界面与操作；后续设计见 [design.md](design.md)，实现与验收进度见 [refactor-progress.md](refactor-progress.md)。代码行为与实机接收效果分开判断，硬件依据见 [hardware.md](hardware.md)。

## 当前功能范围

默认启用 A/B 两个 Radio Slot，可在 Settings → Receive → Slot count 设置 1／2／3／4 项，每页显示两个。主屏幕不区分 VFO 或 MR；`F → 2(A/B)` 在启用的 Slot 间循环选择，`F → 3(VFO/MR)` 切换所选 Slot 的频率来源（直接调频或存储频道）。切到 MR 不覆盖原先的 VFO 频率和频段记忆，切回时恢复；启用两个及以上 Slot 时自动守听全部已启用的 Slot（按各自当前来源），单 Slot 不守听。Slot 的 TX 设置独立，频段预设共享。首次初始化 A 为 145.500 MHz NFM、B 为 438.500 MHz NFM。固件根据频率、模式及探测到的芯片能力选择接收路径，无需手动选择芯片。模式为 `NFM / WFM / AM / LSB / USB`，没有 `Auto`。

默认编译 **已开放 BK4819 NFM 发射与功放**：在当前 Slot 菜单把 `TX Enable` 设为 On 后按住 PTT 发射（初始均为 Off）。首次发射请接假负载核对功率与频偏，并只在有执照许可的频率发射；`make ENABLE_TX=0` 可生成仅接收固件，`make ENABLE_FC=0` 可去掉 FC（`F → 4` 改为提示 `Not supported`，省约 1.3 KiB）。已支持命名频道和频道模式；`F → 4` 可启动 FC 频率捕获、`F → *` 可启动向前 Seek。旧扫描 / 频谱 / Loot 应用已从源码删除。

## 刷写固件

连接编程线，关闭电源，按住 PTT 开机进入 Bootloader。在仓库根目录运行 `make flash PORT=/dev/cu.usbserial-1420`；Linux 示例串口为 `/dev/ttyUSB0`，替换为实际设备路径。命令会先编译再刷写，全部块确认后重新开机。失败时重新进入 Bootloader 并完整重刷。

刷机不初始化 EEPROM；详细步骤和依赖见 [工具说明](../tools/README.md#刷机)。

## 首次开机与初始化

已有有效 `UVR2` 配置时，开机恢复上次保存的频率和参数。旧 Hawk5、LOSEHU 或未知配置不会自动迁移。

无法读取有效配置时进入初始化界面，EEPROM 写入保持锁定。初始化会覆盖低地址的配置区域，也可能覆盖旧固件在该区域的设置或频道内容；操作前备份 EEPROM 并核对本机存储布局。

1. 显示 `No UVR2 config` 时，按 `0` 进入确认。
2. 显示 `Initialize UVR2?` 时，按 `1` 初始化；按 `EXIT` 取消确认。
3. 写入及回读校验成功后自动重启，默认进入 **2m，145.500 MHz，NFM**。

`EEPROM unknown / Cannot initialize` 表示无法初始化；`Write/verify failed` 表示写入或校验失败。`EXIT` 返回初始提示，不会绕过初始化进入接收界面。开机检测到 `EXIT` 按键也会进入该界面。

初始化只写 `0x0800–0x0FFF` 的两份 1024 B 配置槽，不进行全片擦除。具体保护范围见 [hardware.md](hardware.md#必须保护的存储区域)。

## 快速开始

1. 在主界面输入 `438*500`，按 `MENU`，目标为 **438.500 MHz**。进入 70cm 频段时采用该频段预设；初始参数为 NFM。
2. 短按侧键 1，或短按 `F` 再短按 `1(Band)`，依次切换内置快捷频段。
3. 短按侧键 2，或短按 `F` 再短按 `0(FM)`，循环切换当前频率可用的模式。
4. 按 `▲ / ▼` 按当前步进调频，按住可连续调节。
5. 短按 `MENU` 修改模式、步进、带宽、静噪、RX Tone 或发射参数；按 `EXIT` 返回。

成功调谐后约 1.5 秒安排保存，连续修改会延后保存。关机前留出写入时间；主界面调谐没有保存成功提示；频段编辑器有明确的保存结果。

## 主界面与按键

主界面顶部保留 8 像素公共状态栏，每个 VFO 组件高 28 像素。组件黑底横条显示选中箭头、A–D、预设修改标记、完整频段名称及右对齐模式。正文左侧空闲时显示步进，接收音频打开时显示 RX 和阶梯信号图标。右侧没有名称时显示大号频率（中字放大两倍加粗），大字最多 7 个字符（含小数点），其余位数用小字放在单位上方，保持实际频率精度，例如 `1339.99` + `998`；低于 1 MHz 使用 kHz，省略无意义的末尾零。有 MR 频道名或广播 RDS 电台名（PS）时，正文改为同样大小的名称，完整频率以紧凑格式（如 `438.50625MHz`）移到黑底横条最右侧，模式移到正文右下角；名称放不下的部分用小字接在右上角，再超出就裁掉。广播的 RadioText 内容变化后，占用该卡片的整个黑底横条 10 秒（频段名和频率暂时让位），之后恢复，直到电台换下一段文本；放不下的部分裁掉。所有文字都不滚动；输入频率和搜索期间始终显示大号频率。名称编辑与中文字库尚未实现。A 位于 y=8、B 位于 y=36，选中箭头表示调谐和菜单归属，RX／信号仅属于实际接收项，它可能并非选中项；探测时显示 DW，其余行显示步进。两行显示不表示同时接收；Dual Watch 开启时按参与组轮询。C/D 使用同一布局分页，三项时选中 C 显示 B/C。错误、超时、操作反馈和守听提示统一显示在对应 VFO 的黑底状态条，约 2.5 秒后恢复，长文案直接裁掉；频率／名称正文和另一行保持显示。菜单产生提示时暂时显示 VFO，提示结束恢复菜单。量化确认界面使用相同的完整频率格式。详见 [VFO 首屏布局](ui-layout.md)和 [RDS 接收与解析](rds.md)。

VFO 标识后的 `*` 表示当前模式、步进、带宽或静噪与该频段已保存预设不同，**不表示尚未保存**。接收音频打开时，该 VFO 正文左侧显示 RX 与阶梯信号图标；不同芯片的信号读数用于参考，不是统一校准的测量结果。

| 按键 | 主界面操作 |
| --- | --- |
| `▲ / ▼` | 增加 / 减少一个步进；按住连续调节 |
| 数字 `0`～`9` | 在选中 VFO 行原地输入频率，并输入第一位数字 |
| 短按 `F → 1(Band)` | 切换到下一个快捷频段，与侧键 1 相同 |
| 短按 `F → 2(A/B)` | 切换选中 VFO，并恢复它的完整 RX 参数；失败时恢复原接收和选择 |
| 短按 `F → 6(H/M/L)` | 当前 VFO 发射功率 Low → Medium → High → Low，自动保存并提示；MR 频道只读 |
| 短按 `F → 0(FM)` | 循环切换当前频率可用的解调模式，与侧键 2 相同 |
| 短按 `F` | 等待副标快捷键；顶部状态区右侧、电池左侧显示 `F` |
| 短按侧键 1 | 切换到下一个快捷频段，恢复该频段最后成功应用的频率，并应用已保存预设 |
| 短按侧键 2 | 切换当前频率可用的模式 |
| 短按 `MENU` | 打开选中 VFO 参数菜单，标题为 VFO A／VFO B |
| 长按 `MENU` | 打开全局设置 |
| 短按 `EXIT` | 关闭监听 |
| 长按 `F`（副标 `#`、钥匙图标） | 锁定 / 解锁键盘 |
| `PTT` | 当前 VFO 的 TX Enable 设为 On 后，按住进行 NFM 发射，松开恢复 RX；只开放 136–174／400–470 MHz，要求本机功率校准和有效供电 |

侧键不承担旧手册中的监听、手电筒或 SSB ±50 Hz 微调功能。在参数菜单和频率输入中，侧键不执行全局频段 / 模式切换。

副标快捷键采用顺序操作，无需同时按住。目前实现 `F → 1` 切频段、`F → 0` 切模式、`F → 2` 循环 VFO、`F → 3` 切换 VFO/MR、`F → 6` 切换发射功率、`F → 4` 频率捕获和 `F → *` 搜台；其他目标键显示 `Not supported`，不进入频率输入。执行一次后退出前缀；再次短按 `F` 或短按 `EXIT` 可取消，3 秒未执行也自动取消。PTT、长按 F 锁键、进入设置或其他界面会清除前缀。菜单中 F 保留原有局部操作，数值编辑期间短按 F 不执行操作。侧键功能暂不可配置，后续设计见 [统一绑定规则](design.md#33-f-前缀与副标快捷键统一绑定规则)。

键盘锁定后，两个侧键也被锁定，防止误调谐。默认 PTT 不受键盘锁影响；全局设置 `Lock PTT too` 为 `On` 时，PTT 也被屏蔽。该选项不改变 TX Enable 或板级发射范围。

## 频段与独立参数

侧键 1 的循环顺序为 **LW → MW → SW → FM Radio → Airband → 2m → 70cm → LW**。VHF、UHF 是宽范围兜底配置，不加入侧键循环；可通过频率输入或连续调频进入。

下表是首次初始化的默认值，范围用于固件匹配，不能据此认定整机在全部频率上都有可用接收能力。

| 频段 | 匹配范围 | 初始频率 | 模式 | 步进 | 带宽 | SQ |
| --- | --- | --- | --- | --- | --- | --- |
| LW | 150 ≤ f < 530 kHz | 225 kHz | AM | 1 kHz | 6 kHz | 0 |
| MW | 530 ≤ f < 1800 kHz | 999 kHz | AM | 9 kHz | 6 kHz | 0 |
| SW | 1.8 ≤ f ≤ 30 MHz | 7.1 MHz | AM | 5 kHz | 6 kHz | 0 |
| FM Radio | 64 ≤ f ≤ 108 MHz | 95.9 MHz | WFM | 100 kHz | 固定 | 0 |
| Airband | 118 ≤ f < 137 MHz | 125 MHz | AM | 8.33 kHz | 6 kHz | 0 |
| 2m | 144 ≤ f < 148 MHz | 145.5 MHz | NFM | 12.5 kHz | 12 kHz | 4 |
| 70cm | 430 ≤ f < 440 MHz | 438.5 MHz | NFM | 12.5 kHz | 12 kHz | 4 |
| VHF | 30 ≤ f < 300 MHz 的兜底 | 151 MHz | NFM | 25 kHz | 12 kHz | 4 |
| UHF | 300 ≤ f ≤ 1340 MHz 的兜底 | 445 MHz | NFM | 25 kHz | 12 kHz | 4 |

重叠时优先匹配更窄的频段，例如 95.9 MHz 匹配 FM Radio。当前可输入范围为 150 kHz～1340 MHz，但频率和模式组合仍须有可用接收路径。

各 VFO 独立保存每个频段最后成功应用的频率和参数，共享独立频段预设。调到其他频段时恢复其频率并应用预设；同频段内保留当前 VFO 参数。开机恢复最后选中 VFO 和其状态，包括临时调整，不强制替换成预设。F→2 恢复完整当前参数，不重新套用预设；输入、搜索、确认、菜单及 PTT 生命周期内不能切换。目标模式不可用时不静默改变模式或选择。

### 频段列表编辑器

长按 `MENU` 进入 `Settings`，选择 `Band presets` 按 `MENU`。列表包含全部 9 个内置频段，`▲ / ▼` 选择，`MENU` 编辑，`EXIT` 返回设置。频段名、范围和侧键循环顺序采用内置定义，当前不能新增、删除或改名。

编辑界面显示所选频段名，`▲ / ▼` 选择项目，`* / #` 向后 / 向前调整，`MENU` 也可向后调整。模式、步进、带宽使用与主界面相同的能力筛选；模式改变时必要的步进和带宽自动调整，WFM 带宽为 `Fixed`。

| 项目 | 操作 |
| --- | --- |
| `Mode / Step / BW / SQ / RX Tone` | 编辑所选频段的模式、步进、带宽、静噪、接收亚音草稿 |
| `Use current` | 按 `MENU` 将最后成功接收的当前 VFO 参数复制到草稿；仅可用于当前频段 |
| `Defaults` | 按 `MENU` 将该频段内置默认参数复制到草稿 |
| `Save` | 按 `MENU` 校验并保存所选频段预设，成功返回列表 |

`EXIT` 丢弃全部草稿并返回列表。`Use current` 和 `Defaults` 都需要再执行 `Save` 才会保存。恢复默认值不改变上次频率、其他频段或全局设置。

保存时以所选频段上次成功使用的频率校验模式和参数。缺少接收芯片 / SSB 补丁时显示原因；`Save failed` 表示写入或回读校验失败，原预设保留，草稿仍可重试。成功显示 `Saved`：预设在下次进入该频段时应用，当前接收保持原配置。即使编辑的是当前频段，同频段继续调频仍保留当前 VFO 参数；先切到其他频段再切回来即可应用。

当前保存为 UVR2 **格式 9**，两份 1024 字节槽位位于 `0x0800–0x0FFF`。用户频道单独保存在 `0xB000–0x113FF`。旧格式一律不读取：升级后开机进入初始化页，需确认后重新初始化。不会主动擦写原机 `0x1E00–0x1FFF` 校准区或 EEPROM 尾部 SI4732 补丁。

## 频率输入

频率直接在选中 VFO 的原频率位置输入，另一行保持显示；输入草稿不会调谐或保存。输入始终以 **MHz** 为单位，即使主界面当前显示 kHz。光标用下划线表示，屏幕上没有其他输入提示，顶部标题保持不变；输入的值不合法时，卡片页眉显示 `Invalid value`，继续编辑即消失。输入期间守听照常运行，确认后调谐时才暂停。

菜单里的数值（例如电池 Cal voltage）同样原地编辑：项目名不变，只有右侧的值变成草稿加光标，单位照旧；不合法时顶部标题短暂显示 `Invalid value`。

| 操作 | 按键 |
| --- | --- |
| 输入数字 | `0`～`9` |
| 输入小数点 | `*`；先输入整数部分，例如 `0*401` |
| 确认 | `MENU` |
| 删除最后一位 | 短按 `EXIT` |
| 立即取消整个输入 | 长按 `EXIT` |
| 取消输入 | 内容为空时短按 `EXIT`；PTT、短按 F、上下键和侧键在编辑期间不执行操作 |

示例：`0*401` → 401 kHz；`95*925` → 95.925 MHz；`438*500` → 438.500 MHz。建议显式输入 `*`，避免依赖自动补小数点。超出允许范围时不会提交。

硬件无法精确表示目标频率时显示 `Apply ...?` 和实际将调谐的频率；按 `MENU` 应用，按 `EXIT` 取消。只有频率量化改变需要这个确认，切换芯片本身不要求确认。

## 模式与接收芯片

侧键 2 或 `F → 0` 按 **NFM → WFM → AM → LSB → USB** 循环，跳过不支持的模式。仅剩当前模式时显示 `No option`。`0(FM)` 在本项目中是解调模式入口；FM 广播通过频段选择或频率输入进入。

| 模式 / 组合 | 当前接收路径 |
| --- | --- |
| NFM | BK4819；固件模型下限为 15.88 MHz |
| WFM，64～108 MHz | 优先 SI4732；缺失时可用探测成功的 BK1080 |
| AM，≤30 MHz 且有 SI4732 | SI4732 |
| AM，其他有 BK 接收路径的频率 | BK4819 的现有 AM 实现 |
| LSB / USB，≤30 MHz | SI4732，只有在提供受信任的全量补丁 CRC32 且实际 EEPROM 校验通过后可用；默认编译禁用 |

NFM 是对讲机窄带 FM，WFM 是广播宽带 FM。95.925 MHz 上从 WFM 切换到 NFM / AM 会自动选择对应接收路径，参数兼容调整立即应用。需要时自动调整带宽或最小步进；频率未改变就不弹确认。界面始终显示实际选择的明确模式。

补丁和固件扩展频段的实机效果须单独验证，参见 [hardware.md](hardware.md)。

## 当前 VFO 参数菜单

短按 `MENU` 打开菜单；`▲ / ▼` 选择项目，`*` 增加 / 向后切换，`#` 减少 / 向前切换，`MENU` 与 `*` 相同。`RX Mode` 项的三个修改键均向后循环。`EXIT` 返回主界面；修改成功后立即生效，返回不会撤销。

菜单不设分组标题，直接使用 RX／TX 项目前缀，同类项连续排列：RX Mode、RX Step、RX Bandwidth、RX Squelch、RX Tone、TX Enable、TX Power、TX Shift、TX Offset（Split 时显示为 TX Freq）、TX Tone，最后是 `Reset to defaults` 和 `Save as channel`。项目统一左对齐、数值右对齐，当前选中项整行反白，每屏最多五项，超出后滚动。

| 项目 | 含义 |
| --- | --- |
| `RX Mode` | 当前明确解调模式，跳过不可用模式 |
| `RX Step` | 调谐步进，使用可读单位，如 `12.5 kHz`，跳过当前组合不支持的值 |
| `RX Bandwidth` | 接收带宽，使用可读单位；WFM 显示 `Fixed` |
| `RX Squelch` | 静噪等级，0～10 |
| `RX Tone` | Off、50 个 CTCSS 频率、104 个 DCS 正码／反码；仅 NFM 可编辑 |
| `TX Enable` | 该 Slot 的发射意图，默认 Off；不是硬件许可 |
| `TX Power` | Low / Medium / High，使用对应原厂校准档；缺少校准的档位拒绝发射 |
| `TX Shift` | `Off`（与接收同频）、`+` / `-`（中继频差，发射 = 接收 ± TX Offset）、`Split`（发射用 TX Freq 指定的频率） |
| `TX Offset` / `TX Freq` | Shift 为 +/- 时是频差（如 `600 kHz`），为 Split 时是发射频率（未设置显示 `Same`）；Shift 为 Off 时显示 `--`、不可编辑。频差和 Split 频率各自保存，切换 Shift 不会丢 |
| `TX Tone` | Off、CTCSS、DCS 正码／反码，独立于 RX Tone 保存 |
| `Reset to defaults` | 把模式、步进、带宽、静噪、RX Tone 恢复为当前频段的预设；频率和 TX 设置不变 |
| `Save as channel` | 存成频道：选频道号 → 已占用时确认覆盖 → 输入名称 → 保存 |

## 频道保存与频道模式

在 Slot 菜单选择 `Save as channel`：VFO 默认定位到首个空频道，MR 默认定位到当前频道。`▲ / ▼` 选择编号，按 `MENU` 继续；已占用的频道需再按一次 `MENU` 确认覆盖，`EXIT` 返回。随后进入名称输入（覆盖时预填原名称），确认后写入并回读校验；名称留空则保存为 `CH nnn`，在名称输入里退出则不保存。

## VFO 与频道模式

`F → 3(VFO/MR)` 只切换当前选中 Slot。进入频道模式时恢复该 Slot 记住的频道编号；编号失效时尝试第一个已保存频道，没有频道则保持 VFO 模式并提示。频道模式下横条显示 `CH nnn`，正文显示频道名称；`▲ / ▼` 在已保存频道间循环。频道参数只读（菜单里改参数提示 `VFO only`），`Save as channel` 可覆盖当前频道或另存。退出频道模式恢复该 Slot 原有频率和参数。数字频率输入、频段快捷键、模式快捷键和 Seek 仅在 VFO 模式使用；先按 `F → 3` 切回 VFO。

频道编号为 1–200，固定编号不因覆盖而移动。名称最多 16 个 ASCII 字符（预留给以后 8 个双字节中文字符）。频道记录保存 RX 频率、模式、步进、带宽、静噪、RX Tone、名称和完整 TX 设置（Shift、频差、Split 频率、亚音、功率、开关），独立 EEPROM 区双副本校验。

主界面修改形成当前 Slot 的临时覆盖，并随成功调谐保存以供重启恢复；不会自动改写频段预设。改乱了可用 `Reset to defaults` 恢复预设。需要保存为预设时，在 `Settings → Band presets` 选择当前频段，使用 `Use current` 后执行 `Save`。切换至非 NFM 模式时清除当前 RX Tone。

RX Tone 的 Off 只使用 Squelch 门限；启用亚音时须同时满足门限和匹配亚音才打开音频（Squelch=0 也不绕过亚音）。CTCSS 显示如 `67.0 Hz`，DCS 显示如 `D023N`／`D023I`。*/# 顺序增减并循环所有选项，MENU 与 * 相同；没有自动亚音扫描。

TX Offset / TX Freq 在菜单当前行原地编辑，单位 MHz，进入时显示当前值，首个数字替换整个草稿。* 为小数点，MENU 确认，短按 EXIT 删除、长按 EXIT 取消；输入 0 清除（频差为 0 等同同频，Split 频率为 0 等同同频）。频差最大 100 MHz；Split 频率须为 BK 支持范围内的 10 Hz 整数倍，不接受 660～840 MHz 间的接收空隙。不合法时保留旧设置和草稿并提示 `Invalid value`。保存发射设置不会重新调谐接收，也不会自动允许发射；PTT 仍按实际发射频率、模式、设备能力及授权检查。

## 全局设置

长按 `MENU` 进入 `Settings`。`▲ / ▼` 选择，`MENU` 进入子菜单，`* / #` 增减值，`EXIT` 返回上层并最终退出。

根菜单依次为 `Display`、`Receive`、`Transmit`、`Lock PTT too`、`Battery`、`Band presets`、`Channels`、`About`（原 System 的三项已并入 About）。进入设置、频段编辑或文本输入时，主界面的接收和守听在后台继续运行，广播不会中断。Display 和 Receive 直接显示参数，不再进入 Backlight、Squelch、Hardware 子菜单；About 固定放在根菜单最后一项。普通设置修改后无需按 MENU 保存，EXIT 返回不会撤销。

Reset prefs 保留电池校准／曲线、接收硬件与静噪工程参数、Mic／Deviation 保存字段，以及全部 VFO／频道／频段预设和守听状态；它不初始化 EEPROM。Beep 暂无可用按键音路径，已从菜单移除；自动锁键尚未开放。发射仍受 TX Enable、板级频率范围、功率校准和供电检查约束。

## 多 VFO 配置迁移

当前 UVR2 格式为 9，记录内容约 750 B，双 1024 B 配置槽位于 `0x0800–0x0FFF`；旧格式（4–8）不再读取或迁移。用户频道 200 个、每个两份 64 B 副本，位于 `0xB000–0x113FF`；旧版 48 B 频道记录不识别。原厂校准与补丁仍只读。

## Slot 数量与多路守听

在 `Settings → Receive → Slot count` 设置 1–4。F→2 循环，四项为 A→B→C→D→A；页面自动保持选中项可见。减少数量不删除隐藏项频率／参数；隐藏当前项时回到 A。

**守听没有开关**：Slot count 为 2 及以上时守听全部已启用的 Slot；只想听一路就把 Slot count 设为 1。规则如下：

- **常驻源**（广播，或静噪为 0 的频道）一直有声音，只放一路：选中的那个优先，否则第一个。
- **事件源**（静噪大于 0 的对讲／中继／航空频道）平时安静，轮流检查；有人讲话就插入，广播暂时静音。
- **先到先得**：一路正在出声时，其他频道有人讲话也不插入。
- **讲话不限时**；讲完后在该频道静音停留 2 秒等回复，之后广播恢复、继续轮询。
- 选中箭头只表示 PTT／菜单／调谐归属，没有音频优先权。标题 `DW A/B/C/D` 显示正在出声的 Slot，全部安静时为 `DW -`；正在检查的卡片左侧显示 DW。

**性能提示**：所有事件源共用一颗 BK4819，只能逐个检查，每个约 200 ms。频道越多，轮一圈越慢，短促的呼叫可能漏掉；一路正在出声时其他频道不检查。广播在 SI4732 上时不受轮询影响；若常驻源是静噪为 0 的 BK 频道，每轮检查都会让它断音约「事件频道数 × 200 ms」。是否开到 4 路请按需取舍。

只有改动射频的操作（调谐、改接收参数、切换 Slot／来源、搜索、FC、PTT）才暂停守听并恢复选中项，约 2 秒后继续；翻菜单、输入频率草稿和确认页不打断守听，广播照常播放。守听不会把后台频率保存为选中项。

**回话**：某个频道正在出声，或在讲完后的 2 秒内，按 PTT 会回复这个频道，使用它自己的发射设置（TX Enable、发射频率、亚音、功率）；它不能发射时提示原因，不会改发到选中的 Slot。其他时候 PTT 发射到选中的 Slot。回话不改变选中箭头，发射中的卡片显示 TX，松开后停在该频道收听，2 秒后恢复守听。SQ0 不会把纯噪声当作事件命中。SSB 不参与守听（`DW: SSB off`）；只剩一个独立来源时不守听（`DW: one source`）；方案不可用显示 `DW: unavailable`。检测门槛与漏检率仍待设备验证。详见 [多 VFO 与多路守听](multi-vfo-design.md)。

顶部状态栏在 VFO、设置及其他页面共用同一布局：电池按全局 Show charge 设置显示图标、百分比或电压，状态图标按电池实际宽度靠右排列，标题在剩余宽度内裁剪；低电量闪烁时仍保留电池占位。F 前缀提示仅在 VFO 等待快捷键时出现。

## FC 频率捕获

连续 VFO 主界面按 `F → 4(FC)` 捕获附近正在发射的强载波。检测期间当前 VFO 的黑底横条显示检测器当前范围（`FC VHF`／`FC UHF`），模式位置显示所选范围（`Auto`／`VHF`／`UHF`），正文实时显示最近一次测到的有效频率，尚无读数时显示 `---`。默认 Auto，每个滤波范围两次尝试后轮换；任一侧键循环 Auto／VHF／UHF。连续两次有效结果相差不超过 3 kHz 才停止检测，并直接把入口选中的 VFO 调到该频率（NFM，关闭 TX Enabled 和 RX Tone，清原频道编号／名称草稿），与手动输入频率一样保存；之后可用 Name／Save 存成频道。不必等自动确认：按 MENU 立即采用当前显示的读数；按 EXIT 退出并恢复原接收，检测期间 PTT 不发射，RDS 暂停，其他 VFO 不变。FC 只借用 BK4819：开始时把设备为 BK 的 Slot 暂时移出守听（正在出声的对讲让位），广播 Slot 照常守听播放；FC 结束后这些 BK Slot 立即恢复守听。取消不保存。MR 模式须先 F→3 切回 VFO。

FC 只能捕获近处（约数米内）正在发射的强信号，例如另一台对讲机按下 PTT；远处的广播或中继太弱，读数会一直是 `---`。FC 没有超时，没有稳定结果就一直检测，按 MENU 直接采用屏幕上当前的读数（还没有读数时不响应），按 EXIT 退出；长时间开着不会损伤芯片，耗电与一直接收相当。FC 不识别解调模式或亚音，也可能捕获谐波／强信号误报；频率准确度仍需实机验证。详见 [FC 实现与验收](fc-design.md)。

发射被拒绝时（例如 TX disabled、TX: NFM only、TX HW locked），提示临时显示在选中 VFO 的黑底横条中，替换频段文案，保留 A–D 标识和模式；长文案裁掉，提示结束恢复原横条。频率／名称正文保持显示，调谐错误、Seek 状态、频道保存反馈和守听提示也使用同一状态条。

PTT 发射已接入 BK4819 NFM 实际 HAL；初始化默认 TX Enable 仍为 Off，需在当前 VFO 菜单启用。Same／独立 TX 频率及 TX Tone 均进入发射方案，F→6 选择功率档。松开 PTT、超时或供电异常先关闭功放，再恢复原 RX；默认构建已开放，尚未用仪表测量射频输出。实现与校准布局见[PTT 发射链路](tx-design.md)。
