# 极简重构：第一批实现与当前操作

更新日期：2026-10-10。分支：`codex/minimal-radio`。完整目标见[极简无线电设计](design.md)。本文描述当前重构代码，尚未刷入实机；历史版操作见[原用户手册](user-manual.md)。

## 已完成的第一批

- 新增独立的 `radio-model`：参数使用整数 Hz，模式明确为 FM、WFM、AM、LSB、USB，不包含 AUTO。
- 内置 LW、MW、SW、FM Radio、Airband、2m、70cm，以及 VHF/UHF 兜底频段；每段有独立默认参数。窄范围优先，快捷循环顺序固定。
- 集中计算接收方案，选择与先前芯片无关；SI 缺失和 SSB 补丁缺失有明确结果。芯片探测通过各自驱动执行，并缓存。
- 主界面只加载一个已存储 VFO，保持旧 EEPROM 布局。选择此前活动记录，记录不存在时回退首个现有 VFO；没有 VFO 时使用不自动写入记录的默认状态。
- 数字输入和上下键走同一 Hz 模型；可以跨频段和芯片调谐，不按当前芯片范围回绕。
- 模式或频率需要参数调整时先展示并确认；WFM 显示实际量化后的频率，移除 SI 驱动的额外 50 kHz 向下取整。
- 修复 SI 补丁启动后 LSB 被留在 USB、同载频切边带未重新发调谐命令、首次 SSB 调谐遗漏 BFO 小数频率的问题。
- 停用旧频道、扫描、频谱、Loot 和多守听入口，裁剪对应链接路径，键盘锁覆盖切频段/模式的侧键。
- 主机回归覆盖模型、频段边界、侧键/菜单、确认取消、无接收路径、旧 VFO 参数读取、探测缓存、SI 边带命令和 BFO。

源码中仍保留了一部分旧模块和内部 `VFOContext`。新的用户模型不依赖它们的枚举；现有驱动与 EEPROM 通过转换函数连接。这是分阶段实现，旧底层接口和存储将在后续继续替换。

## 离线可靠性改造（续）

- 新增小型 `rx-runtime`：持有最后成功应用的接收方案，调谐失败时尝试恢复一次，恢复失败则停止接收输出。
- `VFO1` 的接收成功状态来自 `rx-runtime.active`，未支持频率仍可导航，但不会被标记为已接收。
- `RADIO_StopReception()` 关闭音频输出并复位静噪状态；出于硬件恢复安全，暂时不对射频芯片断电。切回可接收频率时重新配置调谐。
- 静噪开合仅调用 `RADIO_SetAudioOpen()`，不再通过 `RADIO_SwitchAudioToVFO()` 重新初始化接收器。
- 新增无硬件的失败恢复测试，并扩展 VFO 测试覆盖恢复成功与失败情形。
- 实际射频锁定与完整设备状态验证仍需实机；不改变 EEPROM 格式，不启用发射。

## 多守听遗留清理与发射保护

- 保留 `vfos[0]` 作为旧 EEPROM 兼容层，删除多 VFO 切换、扫描轮询以及跨 VFO 音频仲裁。
- 禁用旧扫描模块的多守听调用，旧设置读取不会重新启动多守听。
- 发射入口固定返回 `TX_DISABLED`，旧 EEPROM 的 `allowTx` 位无法开启功放；今后必须独立实现并验证 TX 安全规则才可恢复。
- 不更改实际 EEPROM 读写布局，不进行未经验证的 EEPROM 迁移或硬件刷写。

## 当前操作

| 操作 | 行为 |
| --- | --- |
| 侧键 1 短按 | LW → MW → SW → FM Radio → Airband → 2m → 70cm → LW；应用目标频段默认参数 |
| 侧键 2 短按 | FM → WFM → AM → LSB → USB 中循环，跳过不支持的组合及缺失补丁的 SSB |
| ▲ / ▼ | 按当前步进调频；长按连续调频 |
| 数字键 | 输入 MHz；`*` 是小数点，MENU 提交 |
| 短按 MENU | 当前参数菜单：Mode、Step、BW、SQ、Monitor |
| 参数菜单中的 ▲ / ▼ | 选择参数 |
| 参数菜单中的 `*` / `#` | 增加/减少参数；Mode 项循环可用模式 |
| 确认界面中的 MENU / EXIT | 应用候选频率与参数 / 取消 |
| 长按 MENU | 全局设置 |
| EXIT | 退出参数菜单、取消确认或关闭监听；不切换 VFO |

频段行的 `*` 表示当前参数与该频段默认值不同。WFM 的 BW 显示 Fixed。只提供当前频率、模式和设备组合支持的带宽/步进；不能接收的目标显示 `RX --` 并关闭旧音频，仍可继续调频离开该范围。

例如输入 95.925 MHz，SI 路径按目前驱动的 10 kHz 单位解析为 95.930 MHz；先确认，再应用并显示实际值。BK1080 路径当前是 100 kHz 分辨率，不能假定具有相同精度。以上是当前代码行为，芯片精度和整机效果仍需实机验证。

## 本批边界与后续工作

- 当前参数可通过菜单临时修改，最后有效 VFO 参数通过原来的延迟保存机制保存。各频段上次频率目前只保存在 RAM。
- 频段预设编辑、明确“保存为频段预设”、恢复预设和新版有完整性检查的持久化尚未实现；当前频段表仍是只读默认配置。
- 当前构建按接收运行，PTT 返回 TX OFF。频段默认发射关闭，整机发射允许表尚未建立；后续实现独立发射方案与接收恢复后再启用，不能仅凭 BK 接收或频段标志开启功放。
- 驱动探测目前确认地址应答/既有 BK ID，尚未实现完整 SI GET_REV 识别。
- 旧驱动的部分配置函数仍返回 void；本批尚不保证识别所有硬件命令失败。后续将补齐有返回结果的驱动应用、状态校验和失败回滚。
- 频率量化跨越频段边界时当前明确拒绝并提示 Band boundary，后续按完整规格补有界重新解析。
- 快速调谐尚未增加独立请求合并队列；多守听未启用。
- 现有 EEPROM 的布局和其他频道记录不因本批重构自动清空；新存储格式迁移属于后续阶段。

## 验证

运行 `tests/run.sh` 进行主机回归，运行 `make -j4` 生成固件。主机测试通过硬件桩检查软件状态和下发命令；不能证明实际信号、音频、补丁内容或发射能力已验证。

第一批裁剪后 Flash 约 41 KB，RAM 约 3.7 KB，最终数值以当前构建输出为准。未在本轮执行刷机或 EEPROM 写入。
