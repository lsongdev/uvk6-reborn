# UVK6 Reborn 重构进度

更新于 2026-10-13，当前目标分支：`main`。设计见 [design.md](design.md)，硬件依据见 [hardware.md](hardware.md)。以下均为代码与模拟测试结果，不代表实机验证。

## 多 VFO 与双守听（当前）

- 保存容量四项，启用数量默认两项，可设置 2／3／4；F→2 循环，每页显示两项；数量缩减保留隐藏项参数。
- 独立 Watch 参与项，首批最多两项，总开关默认 Off；有界调谐／稳定／双确认／驻留／信号挂起／错误重试，不复活旧多守听代码。SSB 暂不轮询。
- 选中项、物理接收项及可见位置独立；后台 RX／RDS 不串写，守听不请求保存。手动操作和 PTT 恢复主接收后抢占。
- 格式 7 新双 1024 B 槽在 0x0800–0x0FFF，只读迁移格式 4／5／6 旧槽，首次升级写入中断仍能恢复，保护原厂校准和补丁。
- 新增核心调度、HAL 检测、循环／分页／参与上限／PTT 归属／四项存储与迁移回归。完整行为见 [多 VFO 与双守听](multi-vfo-design.md)。

## A/B VFO（前一阶段）

- 两行 A/B 和 F→2 切换，一次只接收选中项，未实现双守听。RX/TX 参数、频段记忆各自独立，频段预设共享；菜单、输入、搜索和 PTT 归属选中项。
- 单一 RF 运行时，成功才提交选择，失败恢复原方案，恢复也失败则清除接收归属并静音。信号读数和 RDS 不跨行使用。临时提示使用公共状态栏。
- UVR2 格式 6（467 B），原址双 512 B 槽；格式 4／5 迁移到 A，B 按共享预设初始化，不擦除 EEPROM。
- `apps/vfo1.*` 已更名 `apps/vfo.*`，所有应用调用和回归同步更新。
- 主机回归覆盖隔离、迁移、错误恢复、重启及输入／PTT 归属；ARM 构建通过，尚未刷机验收。完整设计见 [A/B VFO](ab-vfo-design.md)。

以下单 VFO 与格式 4 章节是此前阶段记录，当前操作及存储以此节和用户手册为准。

## 已完成

- 芯片代码按 `drivers/{si473x,bk1080,bk4819,st7565,dp32g030}/` 归档；`hal/` 提供按键、屏幕、LED、背光、音频、总线等整机硬件资源接口。屏幕对比度显式传入，应用不直接调用 ST7565。

- 统一用户接收模型：整数 Hz，明确 `NFM / WFM / AM / LSB / USB`；根据 **频率 + 模式 + 接收芯片能力** 生成接收方案。重叠频段 NFM → BK4819，WFM → SI4732（缺失时可用探测成功的 BK1080），不以 BK 窄带 FM 冒充广播 WFM。
- 单接收主界面：频段选择、频率输入、调频、模式、带宽、步进、静噪、S 表；移除多守听、频道扫描和旧应用入口。
- `rx-runtime` 在调谐失败时尝试恢复上一份成功应用的计划；恢复失败后安全静音；静噪开合不再启动接收器。
- 真实发射仍禁止：已实现单 VFO 的 `TxConfig/TxPlan`、PTT/TOT 状态机及设置保存；生产 TX HAL 不提供可验证板级能力或 PA 开启路径，PTT 只返回拒绝原因。
- `Settings → Bands` 独立频段预设编辑器：模式、步进、带宽、静噪草稿，明确保存、取消、复制当前有效参数及恢复默认值；保存不立即改变当前接收，重新进入频段应用。临时 VFO 参数不覆盖频段预设。
- 新 `radio-state`：当前工作状态以及 9 个内置频段各自最后使用的频率、参数与独立预设；接收成功后更新，未支持的目标可暂时显示但不作为持久化成功接收。
- 新 `UVR2` 存储：两个 512 B 槽位、明确字段序列化、CRC32、序号轮换、回读校验、失败重试，不读取旧 `UVR1` 或旧频道作为产品配置；初始化需按键确认。格式 4 增加单 VFO TX Enabled/Power、全局 TOT/Busy Lockout，旧格式不迁移（开发阶段直接明确初始化），使用低 1024 B 区域。旧 MR/VFO 频道导入、导出与写入入口已删除。
- EEPROM 初步硬件资料调查：原机 BL24C64A（8 KiB、32 B 页）；扩容常见 M24M02-DR/BL24CM2A（256 KiB、256 B 页）；旧校准区 `0x1E00–0x1FFF`、不同固件 SSB patch 地址互不兼容。**当前芯片真实型号和 A2/WP 接线仍待实机确认。**
- 主机测试和 ARM 构建已纳入 GitHub Actions。实际固件体积与结果以最新 CI 为准。

## 本轮六项整改

1. **UART**：按命令约束帧长/字段与 EEPROM 读区间；禁止普通 UART 原始 EEPROM 写入，并加入主机解析测试。
2. **Settings / EEPROM 配置**：删除旧 RX-only 产品无关菜单，补全最低背光、SQL 时序等字段，格式 4 双槽持久化，不保留旧格式迁移。
3. **Radio Core**：删除旧 `PARAM_*`、TX 与多 VFO 控制，真实单接收状态通过 `RxPlan` 驱动。
4. **SI4732**：启动、补丁与属性配置传播错误；RSQ 失败时不保留过期 RSSI/SNR。
5. **EEPROM**：只允许写 `0x0000–0x03FF` 两槽配置；按连续 ACK 地址掩码辨识**候选**映射，拒绝离散掩码，物理芯片型号仍以实机丝印为准。
6. **频率与效率**：BK 仅在标称 18–660/840–1300 MHz 规划常规接收；航空频率按 `25kHz/3` 栅格步进；BK 同芯片仅频率变化时跳过冗余 AGC/静噪初始化。

以上仅由主机回归与 ARM 构建核验，不代表完成真实 RF/EEPROM 设备验收。

## 仍待完成

- **已完成的 Core 收敛**：`radio.c` 的旧参数设置、TX 功放和重复调谐已删除；单一 `RadioState` 替代 `VFOContext / vfos[0]`，承载接收状态、信号测量和静噪。
- **物理 EEPROM 确认**：对本机芯片丝印、容量、bank 映射、校准数据、SSB patch 位置进行只读识别；不能仅凭 ACK 数量认定型号。物理确认前不主动进行全片写入或页擦除。
- **功能离线测试**：加入更多驱动错误注入和单一配置状态收敛测试，并检验保存失败与重启场景。
- **实机验收**：BK4819、SI4732 模式和音频切换、S 表读数、SSB patch、掉电恢复、PTT 禁止发射、以及 EEPROM 写回验证。

## 单向自动搜台（F*）

- 主界面先按 `F` 再按 `*` 启动 **向前 Seek**。短按 `▲/▼` 继续原本的手动频率步进，不支持反向自动搜台。
- 仅在**当前选中的频段和模式**内搜索，不因多个频段范围重叠而自动跳频段；越过末尾从当前频段起点继续，第二段搜索返回起点即结束。支持 `EXIT` 取消并恢复原计划。
- BK4819 对 NFM/Airband AM 软件逐频点调谐，用独立于 Monitor/SQ0 的静噪阈值和两次稳定采样；SI4732 WFM/AM 优先使用芯片非循环原生 Seek，经 CTS/STCINT/VALID/BLTF 检查；BK1080 因 76 MHz 频道 bank 切换使用软件步进。
- 所有中间频点只更新临时硬件与搜索显示，不更新 `RadioUserState` 或 EEPROM；仅发现有效信号且最终 `RxPlan` 调谐成功后持久化一次。取消、超时和无信号恢复原计划。
- SSB (USB/LSB) 暂不启用自动搜台。搜索期间暂停普通静噪轮询与 RDS 读取。
- 搜台阈值、硬件音频及扫描速度尚待真实 BK4819/SI4732/BK1080 设备测试调整。

## 单 VFO 收发模型（本轮）

- 决定不引入频道/MR：主 VFO 菜单包含 TX Enable、TX Power，Settings → TX Safety 包含 TOT（默认 120 s）及 Busy Lockout（默认 On）。
- 新建 `tx-model` 做 TX 意图、NFM/BK4819、同频低功率、硬件能力/白名单的纯校验；`tx-runtime` 实现模拟准备、关闭 PA、TOT 锁存、PTT 释放和 RX 恢复；`hal/tx-device` **暂不驱动硬件 TX**。
- `UVR2` 格式 4、双 512 B 槽保存独立 TX 设置；格式 3 不迁移，必须显式初始化。配置区仅低 1024 B，不触及校准区和补丁。
- 未完成：PA/滤波器和校准确认、低电压/温度保护、BK4819 发射真实 HAL 与假负载测量。无硬件发射功能可以对用户开放。

## 单 VFO TX 模型收敛与系统安全检查

- 已彻底移除 `RadioParameters.tx_enabled` 和始终返回 false 的 `RADIO_MODEL_CanTransmit()`：RX 不承担 TX 授权，只有 VFO 的 `TxConfig` 保存用户意图。
- `TX_MODEL_Plan()` 在失败时清空输出计划，并拒绝非法功率档、异常 RX 栅格及 BK 接收能力之外的频点；真实板级 `TxCapabilities` 仍禁用。
- PTT 释放和 TOT 检查由系统主循环优先处理，避免只依靠 VFO 画面更新；忙信道锁定不会被 Monitor 状态绕过。
- 主机模拟 PA 集成测试覆盖 PTT、TOT 超时与释放锁定、准备失败、RX 恢复失败和不写 EEPROM；实际 TX 仍无 RF 输出。
